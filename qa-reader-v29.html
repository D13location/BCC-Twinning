# 01 · 晶体学与几何（从基础概念讲起版）

本版说明：每问按「先备知识 → 逐步推导 → 结论 → 口径边界」重写，符号先定义再使用；数值与归因不变。相关图谱节点：e-twin-elements、p-twin-misorientation、e-fractional、p-gamma-112-asymmetry、c-asymmetry、l-neumann。

01-01 为什么 η₁ 必须是 ⟨111⟩ 而不是 {112} 面内其他方向

思路（先讲清楚按什么逻辑判定）

孪晶的定义是：母体的一部分经均匀切变后变成母体的镜像晶体。这个定义给剪切方向 η₁ 套上三道关卡，我们一关一关过：

  1. 第一关：方向必须在孪晶面内——剪切是沿面滑，方向出了面就不是"孪生面剪切"了。判据 hu+kv+lw=0（方向 [uvw] 垂直于面法线 [hkl]）。(112) 面内方向满足 u+v+2w=0——满足它的方向有无穷多个（[1̄10]、[1̄1̄1]、[111̄]、[31̄1̄]……），其中 ⟨111⟩ 型恰好两个：[1̄1̄1] 与 [111̄]。所以第一关只做过滤，还不能锁定 ⟨111⟩。
  2. 第二关：切完必须"保格点"，而且是映到镜像晶格——切完的原子排列必须还是周期晶体，且取向正好是孪晶取向。精确表述：存在切变量 s 使 S(L)=R(L)（S=切变、R=关于 K₁ 的镜面、L=母体格点集合、R(L)=镜像晶格）。这一关会把绝大多数面内方向淘汰掉：切变量不对，格点就被切散了。
  3. 第三关：同一对相反方向里谁是孪生方向——[1̄1̄1] 与 [111̄] 都能过第二关，但能量不同：沿 [1̄1̄1] 剪 1/6⟨111⟩ 得到镜像堆垛（低能），沿 [111̄] 剪同样量是"反常层错"（高能）。所以孪生方向钉死为 [1̄1̄1]（反方向就是反孪生，见 10-05）。

    4. 下面逐关验证。先备知识

    • 孪晶：一部分晶体相对母体作均匀切变、变成母体的镜像取向。孪生要素四个量：K₁（孪生面）、η₁（孪生方向，在 K₁ 面内）、K₂、η₂（第二不畸变面/方向）、s（切变量）。
    • 切变的硬要求：把格点映到格点。切完的晶体必须还是晶体，且是孪晶取向的晶体——即每个格点都要落到"镜像晶格"的格点上。做不到这一点，切出来的原子排列没有周期性，谈不上孪晶。
    • 方向在面内的判据（立方系）：方向 [uvw] 在面 (hkl) 内 ⇔ hu+kv+lw=0（见 01-08）。
    • 切变矩阵 S：r → r + s·(n̂·r)·d̂。其中 r 是任意点的位置矢量；s 是切变量；n̂ 是 K₁ 面的单位法线；d̂ 是剪切方向的单位矢量。(n̂·r) 是该点到 K₁ 面的距离，s·(n̂·r) 就是该点的滑移量，方向沿 d̂——面内点 (n̂·r=0) 不动，离面越远滑得越多，这就是"均匀切变"的数学写法。
    • 镜面映射 R：r → r − 2(n̂·r)n̂。把每个点沿法线方向翻到 K₁ 面的另一侧、距离不变——这就是关于 K₁ 的镜面反射。
    • 记号 S(L) 与 R(L)：L 是晶格（全部格点的集合）；S(L) 是把每个格点都用 S 变换后得到的集合。R(L) 同理，即"镜像晶格"。

    逐步推导

    1. 第一关（面内过滤）：η₁ 落在 K₁=(112) 面内，需要 u+v+2w=0。⟨111⟩ 型两个方向都通过：[1̄1̄1]：1·(−1)+1·(−1)+2·1=0 ✓；[111̄]：1·1+1·1+2·(−1)=0 ✓。面内其他方向（如 [1̄10]：1·(−1)+1·1+2·0=0 ✓）也通过——第一关只过滤，不定方向。
    2. 第二关（切完是孪晶取向的晶体）：必须验证 S(L)=R(L)——切变后的格点集合恰好等于镜像晶格。验证方法：切变 S 和镜面 R 都是线性映射，线性映射由基矢的像完全决定——只要三个基矢的像对了，所有格点的像都对了。
    3. 取 BCC 晶格的一组基矢 t₁=(a/2)(−1,1,1)、t₂=(a/2)(1,−1,1)、t₃=(a/2)(1,1,−1)。取 n̂=[112]/√6、d̂=[1̄1̄1]/√3、s=1/√2（s 的来历见 01-02）。逐项算 t₁：

      4. - 先把 t₁ 投影到法线：n̂·t₁ = (−1+1+2)/(2√6)·a = a/√6。

      - S·t₁ = t₁ + s·(n̂·t₁)·d̂ = t₁ + (1/√2)(a/√6)([1̄1̄1]/√3) = t₁ + (a/6)(−1,−1,1)。

      - 代入 t₁=(a/2)(−1,1,1)：S·t₁ = (a/2)(−1,1,1) + (a/6)(−1,−1,1) = (a/6)(−4,2,4)。

      - 再对它做镜面 R：R(S·t₁) = S·t₁ − 2(n̂·S·t₁)n̂。n̂·S·t₁ = (−4+2+8)/(6√6)·a = a/√6。R(S·t₁) = (a/6)(−4,2,4) − 2(a/√6)((1,1,2)/√6) = (a/6)(−4,2,4) − (a/3)(1,1,2) = a(−1,0,0)。

      - a(−1,0,0) 是 BCC 格点 ✓（BCC 格点=三个坐标全为整数或全为半整数）。

      1. 对 t₂ 同样计算得 R(S·t₂)=a(0,−1,0) ∈ L ✓；t₃=(a/2)(1,1,−1) 本身在 K₁ 面内（1+1−2=0），切变不动它，R(S·t₃)=t₃ ∈ L ✓。
      2. 三个基矢的 R∘S 像都在 L 内 → 复合映射 R∘S 把整个晶格映到 L 内部：R∘S(L) ⊆ L。再看体积：切变 S 的行列式=1（均匀切变不改变体积），镜面 R 的行列式=−1，所以 |det(R∘S)|=1 → 像格 R∘S(L) 与 L 有相同的晶胞体积。一个"包含在 L 内、体积又与 L 相同"的子晶格只能等于 L 本身：R∘S(L)=L。
      3. 两边作用 R 的逆映射（镜面的逆就是它自己，R⁻¹=R）：S(L)=R(L)。切变把每一个格点映到镜像晶格的格点——第二关通过：d̂=[1̄1̄1] 配 s=1/√2 成立。
      4. 第三关（正反二选一）：沿 [1̄1̄1] 剪 1/6⟨111⟩，各层被推进孪晶镜像位置，堆垛变成 …ABA…（低能构型）；沿 [111̄] 剪同样量，把层推向"正对下方原子排"的位置——高能不稳定堆垛（Sleeswyk 1963"反常层错"）。所以孪生方向是 [1̄1̄1]，[111̄] 是反孪生方向（细节见 10-05/01-06）。
      5. 面内其他方向为什么不行：以 [1̄10] 为例，沿它构造能保持格点的剪切，最小切变量约 3.46——比 1/√2≈0.707 大近 5 倍；而且算出来是 S(L)=L（晶格映回自身、取向不变），那只是普通滑移，不是孪晶。其他非 ⟨111⟩ 方向同理：要么切变量过大、要么切完取向不变。
      6. 为什么"无需 shuffle"：BCC 是单原子基元，格点位置就是原子位置。S(L)=R(L) 意味着每个原子都被切到孪晶位置，不需要额外的原子微调（shuffle）。（对比：反孪生方向必须经迁动，见 01-06。）

        7. 结论：η₁ 必须沿 ⟨111⟩——三道关卡筛下来：(112) 面内只有 [1̄1̄1]/[111̄] 这一对 ⟨111⟩ 方向能配合合理切变量把晶格精确映到镜像晶格（S(L)=R(L)），其余面内方向要么切变量大得多、要么切完取向不变；而这一对里沿 [1̄1̄1] 剪切是低能的镜像堆垛，所以 η₁=[1̄1̄1]。

01-02 为什么 s=1/√2

思路（先讲清逻辑，再上计算）

s 是切变量，定义 = 每层位移 / 面间距。孪生机制把"每层位移"钉死为一个孪生位错步长 b_p=(a/6)[1̄1̄1]（每扫过一个孪生位错，该层就相对下层滑这么多），面间距是 d_112——两个量一除，s 就唯一确定了，没有自由参数。但还可以再问一层："为什么偏偏是 1/√2 这个无理数？"答案在 01-01 的第二关（保格点）：s 必须让切变矩阵把格点映到格点，而 1/√2 的"巧"在于它与方向单位矢的模长 √3、法线单位矢的模长 √6 相乘，三个根号恰好消成整数 6，切变矩阵元全是有理数。所以推导分两段：第一段算 s（只用到定义），第二段解释这个"巧"（为什么它保格点）。

先备知识

  • 孪生位错：Burgers 矢量 b_p=(a/6)[1̄1̄1] 的全位错" title="不全位错">不全位错。它扫过一层 {112} 面，就把该层原子相对上一层滑一格孪晶位置。
  • 面间距（立方系）：d_hkl = a/√(h²+k²+l²)。{112} 面：d_112 = a/√(1+1+4) = a/√6。
  • 切变量 s 的定义：s = 滑移量 / 滑移面间距。"滑移量"是相邻两层之间的相对位移，"面间距"是两层的距离——位移除以距离，就是"每单位垂直距离切了多少"。

逐步推导

  1. 相邻两层的相对位移被孪生机制钉死：每扫过一个孪生位错，层间相对位移恰好是 b_p=(a/6)[1̄1̄1]。所以滑移量=|b_p|。
  2. |b_p| = |(a/6)(−1,−1,1)| = (a/6)·√(1+1+1) = a√3/6。
  3. 面间距 d_112 = a/√6。
  4. 代入定义：s = |b_p|/d_112 = (a√3/6)/(a/√6) = √18/6 = 3√2/6 = √2/2 = 1/√2。
  5. 为什么这个值"保格点"（把切变矩阵写出来看）：

    6. - 切变矩阵 S = I + s·d̂⊗n̂（I 是单位矩阵；d̂⊗n̂ 是方向单位矢与法线单位矢的并矢，作用结果正是第 01-01 步 1 写的位移公式）。

    - 代入三个单位向量：d̂=[1̄1̄1]/√3（模长 √3）、n̂=[112]/√6（模长 √6）、s=1/√2。

    - s·d̂⊗n̂ = (1/√2)·([1̄1̄1]⊗[112])/(√3·√6) = [1̄1̄1]⊗[112]/(√2·√3·√6)。

    - 分母三个根号相乘：√2·√3·√6 = √36 = 6。于是 S = I + (1/6)[1̄1̄1]⊗[112]——矩阵元只有 1、±1/6、±1/3 这些有理数。

    1. 有理矩阵元为什么重要：S 作用在任意格点 (x,y,z) 上，位移 = (1/6)·(x+y+2z)·[1̄1̄1]。BCC 格点的 x+y+2z 恒为整数（整数格点显然；半整数格点三个坐标都是"奇数/2"，相加再加倍仍是整数）——所以每个格点的位移都是 [1̄1̄1] 的整数/6 倍，像集保持周期排列（具体是镜像晶格 R(L)，见 01-03）。
    2. 反证：若 s 取别的值，√2·√3·√6 凑不出整数，矩阵元出现无理数——无理系数乘整数格点坐标，像集不再周期排列，切完就不是晶体。
    3. 所以"偏偏是 1/√2"的原因是：s=|b_p|/d_112 由孪生位错步长钉死，而 1/√2 与方向 √3、法线 √6 三个根号相乘恰好消成整数 6，使切变矩阵有理、晶格保持周期性。

      4. 结论：s 不是自由参数，由"每层位移=孪生位错 b_p、层间距=d_112"唯一确定；1/√2 这个值使 √2·√3·√6=6，切变矩阵全有理，这是它保晶格的直接原因。

01-03 为什么能映射成镜面

思路（先讲清逻辑）

01-01 已经用基矢验证了结论 S(L)=R(L)——切变把晶格映到镜像晶格。本问解释"这个映射为什么长成镜面那样"。策略：把"镜面反射"拆成两个特征，逐条对照切变——① 镜面上的点不动；② 镜面外的点翻到另一侧对应位置。逐层看切变：K₁ 面上的点位移为零（因为 n̂·r=0，正是镜面特征①）；其余每层相对下层滑一个孪生位错步长 1/6[1̄1̄1]，滑六层累计正好一个完整格矢 a[1̄1̄1]、堆垛闭合。两者合起来，"不动 + 逐层翻转"就是镜面映射的逐层版本。

先备知识

  • 01-01 已验证的结论：S(L)=R(L)——切变把晶格映到关于 K₁ 的镜像晶格。这里解释这个映射"为什么长这样"的逐层机制。
  • BCC 的 {112} 面堆垛序：六层周期 ABCDEF（第 6 层与第 0 层位置等价）。

逐步推导

  1. 机制分两半。第一半：K₁ 面上的点不动。 对 K₁ 面内任意点 r，它到 K₁ 的距离 n̂·r=0，切变位移 s·(n̂·r)·d̂=0。所以孪生面 K₁ 上所有点原封不动——这恰好也是镜面的特征：镜面上的点在反射下不动。两晶共享同一孪晶面。
  2. 第二半：其余每层相对紧邻下一层滑移 1/6[1̄1̄1]。 第 1 层相对第 0 层滑 1/6[1̄1̄1]；第 2 层相对第 0 层累计滑 2/6[1̄1̄1]；……第 6 层累计滑 6/6[1̄1̄1] = a[1̄1̄1]。
  3. a[1̄1̄1] 是完整晶格平移矢量（BCC 格矢）——第 6 层滑完与第 0 层晶格等价，堆垛闭合。这就是 {112} 面六层周期的几何来源：滑六格刚好回到原位。
  4. 逐层滑 1/6[1̄1̄1] 的具体效果：把 ABCDEF 的堆垛序逐层翻转成它的镜像堆垛（每层原子落到镜面另一侧的对应位置）。切变的位移恰好与"镜面反射所需的位移"逐点相同。
  5. 两个半合起来：K₁ 上不动 + 其余层按 1/6[1̄1̄1] 步长翻转 → 格点集合整体变成 R(L)。又因为 BCC 是单原子基元（格点=原子），整个原子排布变成 (112) 镜面两侧的孪晶排布。

    6. 结论：切变"等于镜面映射"是两件事同时成立的结果——K₁ 面上的点位移为零（镜面条件），其余每层按孪生位错步长平移且六层闭合（堆垛翻转）。

01-04 为什么四要素全有理，无理要素允许吗

思路（先讲清要回答什么）

两个子问题：① 孪晶按四要素的"有理/无理"怎么分类，BCC {112} 属于哪类；② 无理要素允许吗。先钉死"有理"的含义——四要素（K₁/η₁/K₂/η₂）的指数是整数比叫有理；s=1/√2 是数值量、另算，两者不冲突。然后给分类与例子，最后解释 BCC 为什么全有理：01-02 已算出切变矩阵元全是有理数（±1/6、±1/3），有理矩阵作用在有理方向上仍得有理方向，所以 K₂、η₂ 自动落在有理方向。

先备知识

  • 孪生四要素：K₁、η₁、K₂、η₂ 的指数。
  • "有理"指指数是整数比（方向/面的 Miller 指数是整数比）；s 是数值量，另算。

逐步推导

  1. 孪晶按要素的"有理/无理"分三类：type-I（K₁、η₂ 有理，K₂、η₁ 无理）；type-II（K₂、η₁ 有理，K₁、η₂ 无理）；复合（四者全有理）。BCC {112}⟨111⟩ 属复合孪晶。
  2. 无理要素完全可以存在，而且是低对称晶体中的常态——例如 HCP 的 {10̄12} 孪晶，其 K₂、η₂ 是无理的，仍是真实孪晶。全有理是高对称立方晶体的特例。
  3. BCC {112} 为什么全有理：01-02 已算得切变矩阵元为 ±1/6、±1/3——全是有理数。有理矩阵把有理方向映到有理方向，所以第二不变面 K₂、方向 η₂ 自动落在有理方向（K₂=(1̄1̄2)、η₂=[111]）。
  4. 附加事实：BCC 晶格有反演对称（取中心反演晶格不变），而"绕 K₁ 法线转 180° 再反演"与"绕 η₁ 转 180°"两种孪晶取向描述相差一个反演——所以 type-I 与 type-II 两种表述在 BCC 中给出同一取向关系。
  5. 区分两个"有理"：四要素的"有理"指指数为整数比；s=1/√2 是无理数——前者谈方向、后者谈数值，两者不冲突。

    6. 结论：全有理是高对称立方晶体配合有理切变矩阵的结果；无理要素不仅允许，在低对称晶体中还是常态。

01-05 分数位错是不是"无理数"位错

思路（先讲清要回答什么）

问题问的是"分数"两个字是否暗含"无理数"。拆两步：① 词义——分数（fractional）=有理数（整数之比），名字本身不指向无理；② 实体——BCC 芯分解的分数位错，其 b "不必为有理矢量"的原因（带内层错矢量沿带宽连续变化，等价于连续 Burgers 矢量密度分布，连续分布无有理/无理之分）。最后用家族成员表收口：经典偏位错（FCC、确定有理 b、夹稳定层错）、分数位错（BCC、b 可变）、孪生位错 1/6⟨111⟩（恰好有理的成员）。

先备知识

  • 分数（fractional）=有理数（整数之比）。"分数位错"这个名字来自 b 是晶格矢量的分数倍，不指向无理。
  • 相关术语（库内 e-fractional 已核验）：偏位错（partial）、分数位错（fractional）、孪生位错（twinning dislocation）三个词各有指称。

逐步推导

  1. 经典偏位错（partial dislocation）：b 是确定的有理矢量（FCC 的 a/6⟨211⟩），两根偏位错之间夹一片稳定层错。FCC 语境。
  2. 分数位错（fractional dislocation，DV73 术语，BCC 语境）：BCC 芯分解的产物，其 b 不必为有理矢量，夹的是不稳定广义层错带。原因：带内层错矢量沿带宽连续变化，等价于 Burgers 矢量密度的连续分布——连续分布没有"有理/无理"之分。
  3. 孪生位错 1/6⟨111⟩：分数位错家族里"恰好有理"的成员（3 根相加 3×1/6[111]=1/2[111]，回到完整格矢）。
  4. 所以"分数位错是无理数位错"的说法是混淆：名字里的"分数"指 b 是格矢的分数倍；b 本身在经典情形是有理数（1/6、1/3），在一般情形（带内层错连续变化）则无所谓有理无理。

    5. 结论：分数位错不等于"无理数位错"。1/6⟨111⟩ 是有理矢量；分数位错的一般情形 b 无有理/无理之分，因为带内层错矢量连续分布。

01-06 反孪生为什么难——各向异性从哪来

思路（先讲清策略，再上计算）

本问要解释：为什么沿 [1̄1̄1] 切容易、沿它的反向 [111̄] 切难。策略：不先谈抽象对称性，直接算"上层原子相对下层原子走多远"——物理直觉是"原子迎面接近就难（能量陡升）、彼此远离就易（能量平缓）"。分四步：① 在 (112) 面内建立坐标（两个周期方向 e₁、e₂）；② 算出相邻两层的固定错开量——这是全部不对称的来源：相邻层沿 ⟨111⟩ 本来就错开 1/3 周期；③ 写出上层原子到下方最近邻的距离公式 d(u) 并验证静止态（u=1/3）恰好等于最近邻距离 0.866a；④ 分别沿孪生方向（+1/6⟨111⟩）与反方向（−1/6⟨111⟩）剪切，看距离怎么变。最后用 Neumann 原理收口：为什么晶体对称性不禁止这种正反不对称。

先备知识

  • 孪生/反孪生方向：孪生方向 η₁=[1̄1̄1]、反孪生方向 −η₁=[111̄]（整体取反、横线只落在第三个分量），都在 (112) 面内（见 10-05 的思路与验证）。
  • γ 线：沿剪切方向逐步剪切、逐步记能量得到的 γ(s) 曲线（见 10-03）。
  • 最近邻距离：BCC 的最近邻间距为 a√3/2 ≈ 0.866a。

逐步推导

  1. 先建立面内坐标。在 (112) 面内取两个方向：e₁=[1̄10]（自检：1·(−1)+1·1+2·0=0 ✓；周期 a√2）与 e₂=(1/2)[1̄1̄1]（周期 a√3/2——(1/2)[1̄1̄1] 是 BCC 格矢且在面内，所以它是沿 ⟨111⟩ 的重复周期）。
  2. 相邻两层怎么错开的？取第 0 层原点 (0,0,0)、第 1 层原子 (1,0,0)（单位为 a）。把 (1,0,0) 拆成"法向分量+面内分量"：法向分量 = ((1,0,0)·[112]/√6)·([112]/√6) = (1/6)(1,1,2)；面内分量 = (1,0,0)−(1/6)(1,1,2) = (1/6)(5,−1,−2)。再把面内分量按 e₁、e₂ 分解：(1/6)(5,−1,−2) = −(1/2)[1̄10] − (1/3)[1̄1̄1]。即：相邻层沿 ⟨111⟩ 方向固定偏移 −(1/3)[1̄1̄1]。
  3. 以 e₂ 的周期为 1 度量：−(1/3)[1̄1̄1] = −(2/3)e₂，等价于 +1/3 周期。所以上层原子的静止位形落在 ⟨111⟩ 投影周期的 u=1/3 处（u 是沿 ⟨111⟩ 的位置坐标，单位=周期）。
  4. 上层原子到下方最近邻原子的距离公式：横向错开 (1/2)e₁、纵向错开 u·e₂、层间距 d=a/√6，距离 d(u) = a√(2/3 + 3u²/4)。验证静止态 u=1/3：d = a√(2/3+1/12) = a√(3/4) = 0.866a ✓ 就是最近邻距离。
  5. 孪生剪切：上层相对下层滑 +b_p=+(1/6)[1̄1̄1]=+(1/3)e₂，u 从 1/3 走到 2/3。路径中点 u=1/2：d=a√(2/3+3/16)=0.924a——比静止的 0.866a 还远（原子相互远离，轻微鞍部）；终点 u=2/3 与 −1/3 对称等价（晶格镜像对称把 2/3 映回 1/3），回到密排环境 0.866a——终点就是孪晶构型，能量低。整条路径原子没有互相逼近 → γ 缓升。
  6. 反孪生剪切：上层相对下层滑 −b_p=−(1/6)[1̄1̄1]=−(1/3)e₂，u 从 1/3 走到 0。u=0 是正对下一排原子的位置：d = a√(2/3) = 0.816a < 0.866a——最近邻被压缩，且路径上原子迎面接近（距离单调减小）→ γ 陡升。
  7. 这就是各向异性的原子几何来源：相邻层本来就沿 ⟨111⟩ 错开 1/3 周期，孪生剪切把原子推向"两排之间、彼此远离"的低能方向，反孪生剪切把原子推向"正对下一排、迎面挤压"的高能方向。
  8. 对称性表述（DV98 的 Neumann 原理，与上面的几何推导互相印证）：{112} 面内垂直于 ⟨111⟩ 的 ⟨110⟩ 方向是 [1̄10]（自检：(112)·[1̄10]=1·(−1)+1·1+2·0=0 ✓；[1̄10]·[111]=−1+1+0=0 ✓）。其垂面 (1̄10) 是 BCC 的镜面——它同时固定 (112) 面与 [111] 方向、只把面内横向分量 [1̄10] 反演成 [11̄0]，所以 γ 图只关于 [111] 轴镜像对称；这一对称不涉及 ±[111] 的交换，不约束 ±⟨111⟩ 等价——所以正反两个剪切方向能量可以不同。而 {110} 例外：取含 [111] 的 (1̄10) 面（自检：[111] 在面内：(1̄10)·[111]=−1+1+0=0 ✓），其法线 [1̄10] 本身是 ⟨110⟩ 二重轴，绕它转 180° 保持该面、把面内 [111] 映成反向 [1̄1̄1̄]，强制 γ(+f)=γ(−f)。

    9. 结论：反孪生难的原因=相邻 {112} 层沿 ⟨111⟩ 有固定 1/3 周期的错开；反着切把上层原子推向正对下一排的位置（0.816a，被压缩、迎面接近），正着切把原子推向孪晶位置（0.866a 等价密排环境）。DV98 的 层错能">γ 面计算（孪生方向缓、反方向陡）正是这个几何的结果。

02-01 位错芯的定义

思路（先讲清回答结构）

这是定义题，按"一句话定义 → 定量三件套 → 作用"推进：先用教科书原句说清芯是什么（位错线周围、弹性解失效的非线性畸变区）；再给它定量——错排分布 f(x)、芯半宽 ζ、芯能量三件套（Peierls–Nabarro 模型）；最后说它决定什么（Peierls 应力、滑移习性、孪晶倾向）。

先备知识

  • 位错：晶格平移周期性沿一条线被局域破坏的缺陷，由 Burgers 矢量 b 表征。
  • 弹性解：把晶体当作连续弹性介质算出的位移场，在离位错线较远处准确。
  • 错排 f(x)：滑移面两侧原子的相对位移随位置 x（垂直于位错线方向）的分布。

逐步推导

  1. 定义句（教科书口径，保留原句）：位错芯是以位错线为中心轴、向四周扩展到最大畸变量一半的空间；芯内部原子位移偏离弹性解、为非线弹性区，芯周围储存弹性能量（长程弹性场）。
  2. 定量刻画用 Peierls–Nabarro 模型（先定义三个量）：

    3. - 错排 f(x)=b/2+(b/π)arctan(x/ζ)：b 是 Burgers 矢量、ζ 是芯半宽（f 从 b 的 1/4 变到 3/4 的那段距离的一半）。

    - 芯边界：取错排从 b/4 变到 3b/4 处（半宽 ζ 处 f=b/2±b/4）。

    - 半宽数值：刃位错 ζ=d/[2(1−ν)]、螺位错 ζ=d/2（d=滑移面间距、ν=泊松比）；全宽 2ζ=d/(1−ν)（部分教科书以全宽作"芯半径"）。

02-02 为什么芯运动是离散步进、不是连续滑动

思路（先讲清逻辑）

把"连续滑动"需要什么条件和"晶格离散性"提供什么摆在一起看矛盾：连续滑动要求位错在任何中间位置都处于稳定平衡；但晶格是周期性的，位错沿滑移方向的能量是周期函数——只有谷稳定、脊不稳定。两者矛盾 → 0 K 下位错只能待在谷里，应力把势倾斜到谷消失时失稳跳到下一谷，这就是"离散跳变"。有限温度靠 kink-pair 热激活翻脊，宏观平滑，但基本事件仍是一段线跳一个周期。

先备知识

  • 晶格周期性：原子排列沿滑移方向以格矢为周期重复。
  • Peierls 势：位错沿滑移方向平移时，芯内原子构型周期性复原，因此位错能量是位置 x 的周期函数；谷=稳定构型、脊=高能构型。
  • 热激活：有限温度下原子有热涨落，可以翻越能垒；0 K 没有。

逐步推导

  1. 晶格是离散的：位错沿滑移方向平移一个格矢周期，芯内原子构型才恢复原样；中间任意位置芯内原子经过挤压/近接触等高能构型。所以能量是位置的周期函数（Peierls 势），谷是稳定构型、脊是势垒。
  2. 0 K（分子静力学）无热激活：芯只能待在谷里。
  3. 加应力=把周期势倾斜：势能叠加一个线性项（应力做功）。倾斜到临界值时当前谷消失，芯失稳跳到相邻谷——这一步就是一次跳变，对应应力阈值就是 Peierls 应力。
  4. 连续滑动要求任意中间位置都是稳定平衡——但第 1 步说中间位置是高能构型，两者矛盾。所以 0 K 只有"谷→失稳→跳进下一谷"的离散步进。
  5. 有限温度下：kink-pair 热激活翻脊（见 02-05），宏观看起来平滑，但基本事件仍是一段位错线跳一个 Peierls 周期。

    6. 结论：0 K 芯运动是逐格跳变（连续滑动与晶格周期性矛盾）；有限温度靠 kink-pair 热激活，基本事件仍是跳一个周期。

02-03 全位错/偏位错与 1/6⟨111⟩ 的模长

思路（先讲清要回答什么）

两个数先算出来：1/2⟨111⟩ 模长 a√3/2、1/6⟨111⟩ 模长 a√3/6（其 1/3）。然后解释"为什么孪晶必须用小的那根"：1/2⟨111⟩ 扫过=晶格平移一个格矢=结构完全复原、取向不变（那是普通滑移）；1/6⟨111⟩ 是非格矢、六层后闭合的最小矢量，扫过把堆垛翻成镜像（孪晶）。

先备知识

  • 全位错：Burgers 矢量等于晶格平移矢量的位错；扫过之后晶体结构完全复原。
  • 偏位错（不全位错）：b 是格矢的分数倍；扫过之后留下一片错排（层错/孪晶界）。

逐步推导

  1. BCC 最短格矢=1/2⟨111⟩，模长 a√3/2。
  2. 1/6⟨111⟩ 的模长=a√3/6，是它的 1/3——是不全位错。
  3. 为什么孪晶必须用 1/6⟨111⟩ 而不用 1/2⟨111⟩：1/2⟨111⟩ 扫过=晶格平移一个格矢=结构复原、取向不变（这就是普通滑移）；1/6⟨111⟩ 是"非格矢、6 层后闭合"的最小矢量（6×(1/6)[1̄1̄1]=a[1̄1̄1] 才是格矢），扫过把堆垛翻成镜像（孪晶）。

    4. 结论：全位错 b=1/2⟨111⟩（a√3/2）滑移不留痕；孪生位错 b=1/6⟨111⟩（a√3/6，其 1/3）扫过翻堆垛。

02-04 Burgers 守恒怎么检验

思路（先讲清逻辑）

守恒的表述：位错反应前后各支 b 之和相等、结点处流入=流出。检验有两条等价途径：① 代数法——逐分量相加；② 拓扑法——绕分解点画 Burgers 回路，回路在好晶体里连续变形必须仍闭合（连续变形不改变闭合失败量），所以分解产物的 b 之和必须等于母位错。先讲为什么回路是判据，再给两种方法。

先备知识

  • Burgers 守恒：位错反应前后各支 Burgers 矢量之和相等；结点处流入=流出（∑b_in=∑b_out）。
  • 理由：Burgers 回路是拓扑量，绕分解点画的回路在好晶体里连续变形后必须仍闭合——回路连续变形不改变闭合失败量。

逐步推导

  1. 检验方法一（矢量逐分量相加）：3×(1/6)[111]=(3/6)[111]=(1/2)[111]——每个分量独立验证。注意三个 1/6⟨111⟩ 必须同向共线（Sleeswyk 的"三个共线 1/6⟨111⟩"）。
  2. 检验方法二（物理检验）：绕分解点画 Burgers 回路；回路在好晶体里连续变形仍闭合 ⟺ 分解产物 b 之和等于原位错 b。
  3. 两种方法等价：方法一是方法二的代数形式。

    4. 结论：守恒=分叉处各支 b 分量相加等于母位错；回路闭合是它的拓扑理由。

02-05 kink 与 jog

思路（先讲清区别的主线）

kink 和 jog 都是位错线上的台阶，区别在台阶的朝向：kink 的台阶躺在滑移面内（保守运动、无点缺陷），jog 的台阶垂直于滑移面（滑移拖出点缺陷、非保守）。先把两个对象各自定义清楚，再对比表收口。记忆点：kink 在面内、jog 出面。

先备知识

  • Peierls 谷：位错线能量最低的周期位置（见 02-02）。
  • 保守运动：位错在滑移面内滑移，不产生也不消灭点缺陷。

逐步推导

  1. kink（扭折）：位错线位于滑移面内的局部弯折——从一条 Peierls 谷拐到相邻谷的一小段过渡段；不离开原滑移面，无自身 Burgers 矢量（携带的仍是宿主位错的 b），沿位错线保守滑移、可成对湮灭。
  2. kink-pair（扭折对）：一对反号 kink 成对形核、相背扩展，使整根位错线前进一个 Peierls 周期；是位错跨 Peierls 势垒的热激活单元。数值（Mo，FS 势，Cai 2004）：形核能 1.2 eV、kink 迁移 Peierls 应力约 20 MPa。
  3. jog（割阶）：位错线上的台阶，使位错线局部离开原滑移面；割阶滑移产生点缺陷（空位/间隙原子），非保守，常阻碍位错运动。
  4. 两者对比：kink 的台阶在滑移面内（保守、不成对也有意义但通常成对）；jog 的台阶垂直于滑移面（非保守、拖点缺陷）。记忆点：kink 在面内，jog 出面。

    5. 结论：kink=面内小弯（保守）、成对构成热激活单元；jog=出面的台阶（非保守、产生点缺陷）。

02-06 Peierls 应力是应力还是能量，BCC/FCC 差几个量级

思路（先讲清判据）

先钉死量纲：应力=力/面积、能量=力×位移。然后说明"应力"与"势垒"是同一个周期势的一体两面——应力是势的斜率（让谷消失的力）、势垒是势的高度（翻过去要的能量）。最后给 BCC/FCC 的量级（DV98 p.1481 口径）并老老实实算"几个数量级"：500 倍 = log₁₀500 ≈ 2.7 个数量级（说"4 个数量级"高估约 20 倍）。

先备知识

  • 应力=力/面积（单位 Pa）；能量=力×位移（单位 J）。
  • 临界分切应力：让滑移启动所需的切应力。

逐步推导

  1. Peierls 应力是应力（临界切应力，量纲力/面积）。它让位错从当前 Peierls 谷失稳跳到下一谷（02-02 第 3 步）。
  2. 对应的能量量叫 Peierls 势垒（位错翻过一个周期要克服的能量）。两者是同一个周期势的一体两面：应力是势的斜率（力），势垒是势的高度（能量）。
  3. 量级（库内已核验，DV98 p.1481 口径）：BCC 约 5×10⁻³μ，FCC 约 10⁻⁵μ（μ=剪切模量）。
  4. 比值=5×10⁻³/10⁻⁵=500 倍；log₁₀500≈2.7——约 2–3 个数量级（"4 个数量级"高估约 20 倍）。

    5. 结论：Peierls 应力是应力（临界切应力），Peierls 势垒是能量；BCC 比 FCC 高约 500 倍（2–3 个数量级）。

02-07 zonal 的"共线""相邻 {112} 面""复合位错"

思路（先讲清三个词各指什么）

三个词各回答一个问题："共线"=三根 b 为什么平行（守恒强制的拆法：1/2⟨111⟩ 只能拆成三个平行的 1/6⟨111⟩）；"相邻 {112} 面"=三根偏位错各躺在哪（堆垛中连续的三层，各滑一层，扫出的区域才连成三层孪晶片）；"复合位错"=zonal 是谁（分解后的三根组合体，与分解前的螺位错是两个对象）。逐词讲。

先备知识

  • zonal dislocation：三个共线 1/6⟨111⟩ 全位错" title="不全位错">不全位错分布于三个相邻 {112} 面的复合缺陷（Lagerlöf 1993 术语）。
  • {112} 面族：法向 [112]，以 a/√6 间距逐层堆叠，六层周期。

逐步推导

  1. "共线"：三个不全位错的 Burgers 矢量互相平行、沿同一条直线。为什么能共线：分解式 1/2⟨111⟩=1/6⟨111⟩+1/6⟨111⟩+1/6⟨111⟩ 把一个矢量拆成三个平行矢量——Burgers 守恒只允许这种拆法（02-04）；母位错是螺位错（线∥b∥⟨111⟩），拆出的 b=1/6⟨111⟩ 天然平行于 ⟨111⟩，而 1/6⟨111⟩ 又在 {112} 面内，三根偏位错各躺各的面、b 互相平行。
  2. "相邻 {112} 面"："三个相邻面"=堆垛中连续的三层，三个偏位错各滑一层。三面必须相邻，扫过的区域才连成一体三层孪晶片。
  3. "复合位错"与"螺位错"：两个词说的是分解前/后两个对象——1/2⟨111⟩ 螺位错是母位错（分解前）；zonal 是分解后的产物（三根 1/6⟨111⟩ 偏位错+三层层错带，整体运动），所以称复合缺陷。母体是螺位错、产物是复合缺陷，不矛盾。

    4. 结论：共线=三根 b 平行同线（守恒强制的拆法）；相邻面=连续三层各滑一根；复合位错指分解后的三根组合体。

02-08 弓出时两端为什么被约束

思路（先讲清逻辑）

弓出的定义前提就是两端固定：两端自由的位错段在应力下只会整体平移、弯不起来。zonal 的约束是天然的——它两端连着母螺位错线与位错网络结点，端点不能自由移动，应力只能推它弓出扫面（Frank-Read 几何）。每弓出一圈+3 层，复位再弓出 → 3n 离散增厚。

先备知识

  • 弓出：两端固定的位错段在切应力下弯曲成弧。
  • Frank-Read 源：两端钉扎的位错段反复弓出、放出位错环的增殖机制。

逐步推导

  1. 弓出的定义前提就是线段两端固定：两端自由时，应力只让整条位错整体平移，不会弯曲。
  2. zonal 的约束来自它本身是 1/2⟨111⟩ 螺位错分解出的有限线段，两端连着母螺位错线与位错网络结点——端点不能自由平移。
  3. 应力只能推它弓出扫面——这就是 Frank-Read 源的几何。
  4. 每完成一次弓出，扫过区域+3 层（三层孪晶片）；复位后再弓出，3n 离散增厚。

    5. 结论：两端被钉扎（连着母位错线与结点）是弓出的前提；自由段只会整体平移、弯不起来。

02-09 位错芯是什么？线弹性为什么在芯区失效（发散账逐项核验）

思路（先立定义，再逐项走弹性账，最后点明发散的真实含义）

策略分三段。第一段给本体定义句：芯是什么、芯内芯外各是什么状态。第二段把"弹性账"逐项走一遍——螺位错位移场 u_z=(b/2π)θ 出发，算应变（∝1/r）、能量密度（∝1/r²）、柱坐标积分（对数），把每一步写清"由什么推出什么"，看清对数发散长什么样、往哪个方向发散。第三段回答"发散说明什么"：1/r 场在芯外是精确解，发散来自把解外推到 r→0 越界——给出两个越界证据（r=b 时应变多少、γ=100% 发生在哪个半径），再给出补救的两条路（截断+芯能、PN 解析连续分布）。

先备知识

  • 螺位错：位错线 ∥ Burgers 矢量 b 的位错；绕线一圈位移差恰好等于 b。
  • 工程剪应变 γ：角度变形量（无量纲）；弹性极限：金属约 0.1–1%（应变再大进入非线性区）。
  • 能量密度 w：单位体积弹性能（J/m³）；柱坐标体积元 dV=2πr·dr·L。

逐步推导

  1. 本体定义句：位错芯是以位错线为中心轴、向四周扩展到最大畸变量一半的空间；芯内部原子位移偏离弹性解、为非线弹性区，芯周围储存弹性能量（长程弹性场）（graph-data.js node=e-core）。
  2. 螺位错位移场：u_z=(b/2π)θ——θ 从 0 转到 2π，u_z 恰好变化 b（这就是 Burgers 矢量）。
  3. 应变：ε_θz=(1/2)(1/r)(∂u_z/∂θ)=b/(4πr)；工程剪应变 γ=2ε_θz=b/(2πr)∝1/r。
  4. 能量密度：w=σ_θz·ε_θz=μ·(b/2πr)·(b/4πr)=μb²/(8π²r²)∝1/r²（"弹性能∝应变平方"）。
  5. 柱坐标积分：dV=2πr·dr·L，E/L=∫_{r_c}^{R} w·2πr·dr=(μb²/8π²)·2π·ln(R/r_c)=(μb²/4π)·ln(R/r_c)。r_c→0 时 ln(R/r_c)→+∞——能量对数发散，方向向上（能量恒正，不是负无穷）。
  6. 发散的真实含义：1/r 场在芯外各处是线弹性精确解；发散来自把它外推到 r→0——越界证据：r=b 时 γ=1/(2π)≈0.16（16%，已超线性区）；γ=100% 发生在 r=b/(2π)≈0.16b。所以"bug"不是 1/r 场本身，而是"把线弹性解一直用到芯中心"。
  7. 补救一（截断+芯能）：人为设芯半径 r_c，芯外按弹性理论记账、芯内能量单独算（原子模拟/PN），这就是"位错芯"概念在能量账本上的由来。
  8. 补救二（PN 解析）：把位错看成滑移面上连续分布的无穷小位错，错排 f(x)=b/2+(b/π)arctan(x/ζ) 替代中心奇点，能量收敛（定量见 02-01）。

    9. 结论：位错芯=位错线周围弹性解失效的非线性畸变区；对数发散来自把 1/r 精确解外推到 r→0（r=b 时应变已约 16%），补救=芯半径截断+芯能单独记账，或 PN 连续错排分布。

    口径边界：发散方向为 +∞；"应变 100%"对应 r≈0.16b 而非 r=b（r=b 时约 16%）。芯能数值依赖 r_c 选择、不是物理不变量（见 02-10）。

02-10 位错芯的能量怎么计算

思路（三个层次各管一段，收口一个口径事实）

策略按"参数化→解析→原子模拟"三个层次展开，每层写清能算什么、依赖什么输入，最后收口：芯能不是物理不变量，可比较的是构型能差。BCC 特有注意点单独给（芯非平面、分数位错分解、层错能">γ 面判据）。

先备知识

  • 02-09 的对数能量式：E/L=(μb²/4π)·ln(R/r_c)（螺）；刃位错 K·ln(R/r_c)、K=μb²/[4π(1−ν)]。
  • 分子静力学：0 K 下只做能量最小化、不做时间积分（06-03/07 号文件）。
  • γ 面：切开—滑移—接合的能量曲面（03-01）。

逐步推导

  1. 层次一：弹性理论+芯能参数化。总能量拆两段 E=E_el+E_core：芯外 E_el 按对数式记；芯内 E_core 是 r<r_c 那部分，常用 r_c≈b/4~b 口径、量级 ≈μb²/4π。缺陷：E_core 随 r_c 选择而变——芯能依赖芯半径口径，不是物理不变量；物理上可比较的是两种芯构型的能量差。
  2. 层次二：Peierls–Nabarro 解析。把位错看成滑移面上连续分布的无穷小位错 ρ(x)=df/dx，错排 f(x)=b/2+(b/π)arctan(x/ζ)（ζ=芯半宽：刃 ζ=d/[2(1−ν)]、螺 ζ=d/2，d=滑移面间距）；芯区能量=错配能 E_mis=∫γ(f(x))dx（对 γ 面积分）+分布位错之间的弹性相互作用能——两者收敛、模型能量有限。
  3. 层次三：原子模拟。分子静力学：圆柱或偶极子胞、外层按各向异性弹性位移场固定、内区自由弛豫（DV98：直径 32a、内区 931 原子），E_core=(E^dis−E^perfect)/L 取单位线长；势函数 FS/EAM/BOP（芯类别存在势函数依赖：FS 给简并芯、BOP 给非简并芯）；DFT 给小体系芯能与构型基准。
  4. BCC 要点：螺位错芯非平面、分数位错分解，芯能分析靠 γ 面判据 g(b/3) vs 2g(b/6)（DV98 相对单位 Mo 0.77 vs 0.46；绝对 mJ/m² 值归 Vitek 2004）。
  5. 边界教训：Cai 2004——Mo 刃位错固定边界算 0.5 GPa、周期边界收敛后只剩 25 MPa（差 20 倍，10-01 第 7 条）：芯能/Peierls 计算对边界条件极敏感。

    6. 结论：芯能三种算法对应三种口径——参数化（依赖 r_c 选择）、PN 解析（依赖 γ 面输入）、原子模拟（依赖势函数与边界条件）；引用数值必须带口径，物理结论建立在构型能差上（如简并 vs 非简并芯）。

03-01 γ 面的定义与"切开—滑移—接合"

思路（先讲清定义与定位）

先给定义一句话：层错能">γ 面=沿某晶面切开、两半相对滑移 f、再接合的单位面积剩余能量 γ(f)——f 扫过面内一个晶胞就是一张"能量地形图"。然后逐字解释三步操作的物理意义（切开建立能量基准、滑移制造错排、接合算剩余能量），最后定位：γ 面是位错芯与孪晶形核的共同能量输入（芯靠恢复应力 F=−∇γ、形核靠鞍点）。

先备知识

  • 晶面：以截距倒数表示的格点平面 (hkl)。
  • 错排：两个晶块相对平移后，两侧原子不再对齐的量。
  • 单位面积能量：J/m²（mJ/m² 常用）。

逐步推导

  1. 定义：γ 面（广义层错能面）=沿某个晶面切开晶体，两半相对位移任意面内矢量 f，再重新接合，单位面积的剩余能量 γ(f)。f 扫过该面的一个晶胞即构成 γ 表面（一张能量地形图）。
  2. 三步操作各自的物理意义：

    3. - 切开：打断跨面键合，产生两个自由表面——能量基准由此建立。

    - 滑移：两半沿面内平移 f。这一步模拟"广义层错"：f 就是该面上两侧原子的错排量，等价于一根位错扫过该面之后留下的相对位移。

    - 接合：重新贴合并弛豫（允许垂直于面方向弛豫），计算相对完美晶体的单位面积剩余能量 γ(f)。

    1. 整体定位：γ 面是位错芯与孪晶形核两者的共同能量输入：

      2. - 到位错芯：Peierls–Nabarro 模型中恢复应力 F(f)=−∇γ(f)，芯的错排分布 f(x) 由"长程弹性应力=γ 面恢复应力"的平衡方程解出；

      - 到形核：滑移/孪晶路径在 γ 面上的鞍点就是 c_us/c_ut（03-03）。

      结论：γ 面=切开—滑移—接合的能量账单全集；它是位错芯与孪晶形核的共同能量输入。

03-02 GPFE 曲线 γ(λ) 是什么

思路（先讲清为什么要 GPFE）

层错能">γ 面是"连续位移"的曲面，但孪晶是按"层数"长的——第 1 层被剪、第 2 层被剪……所以把位移变量换成层数 λ 记账更直接。GPFE 曲线 γ(λ) 直接回答"几层的孪晶胚能站住"：第一个稳定振荡点就是最小稳定厚度。然后给 FCC/BCC 的判据对比（FCC 每层都有亚稳极小；BCC λ=1 是峰、λ=2–4 无亚稳极小、λ=6 才稳定振荡），并解释 γTBM（峰谷差=增厚一层能垒）为什么给出 BCC 形核≫生长的根源。

先备知识

  • γ 面是"连续位移 f"的能量曲面；GPFE 是它沿孪生路径的逐层采样版本。
  • λ=被剪切的层数（第 1 层相对第 0 层剪、再第 2 层……逐层累积）。

逐步推导

  1. 定义：GPFE（广义面错能曲线）把位移矢量换成层数——λ=1 表示剪了一层（单层层错）、λ=2 两层孪晶胚、λ=3 三层……记录每个 λ 的能量得到 γ(λ)。
  2. 判据（Li 2023 综述 §5.1–5.2，英文原文核验）：

    3. - FCC 的 GPFE 在每个 λ=1,2,3… 都有亚稳极小、λ≥2 后稳定振荡——单层偏位错+层错稳定存在。

    - BCC 在 λ=1 处是局部极大（γ(1) 是形成单层层错的势垒）、λ=2–4 无亚稳极小、直到 λ=6 才稳定振荡（Mo）。即 BCC 无稳定本征层错（Vítek 1968），最小稳定厚度由第一个稳定振荡点决定（Mo 6 层、Fe-50Cr 3 层、高压 3 层/零压 6 层）。

    - 相邻层间峰谷差 γTBM=已有稳定孪晶增厚一层的能垒：BCC 形核后 γTBM 低、FCC 恒定——这是 BCC 形核≫生长、FCC 形核≈生长的能量根源。

    1. 为什么 GPFE 比单看 γ 面直观：它直接回答"几层的孪晶胚能站住"——第一个稳定振荡点就是最小稳定厚度。

      2. 结论：GPFE=按层数记账的 γ 曲线；BCC 无稳定单层/双层/三四层层错、λ=6 才稳定振荡（Mo），所以孪晶按 3n 层离散增厚。

03-03 c_us 与 c_ut 是什么

思路（先讲清为什么有两个数）

两个都是 层错能">γ 面上的"山口"（鞍点），但属于两条不同的路径：滑移路径的山口 c_us（滑移偏位错形核势垒）、孪晶路径的山口 c_ut（孪生位错">孪生偏位错形核势垒）。为什么必须分两个：塑性走滑移还是走孪晶，取决于这两个山口的相对高低——c_ut≫c_us 时孪晶形核远难、塑性走滑移；两者接近时孪晶才有机会。混成一个数就失去预测能力。

先备知识

  • 鞍点：曲面上沿路径的局部极大（山口）。
  • 滑移路径：位错滑移对应的剪切路径；孪晶路径：孪生对应的剪切路径。两者位移方向可以不同。

逐步推导

  1. 两者都是 γ 面上的鞍点值——是广义层错能的一部分：

    2. - c_us（不稳定层错能）：沿滑移路径剪切时能量路径上的第一个极大值=滑移偏位错形核的势垒。

    - c_ut（不稳定孪晶能）：沿孪晶路径剪切的鞍点=孪生偏位错形核的势垒。

    1. FCC 教科书标准图景：滑移偏位错与孪生偏位错都沿 ⟨112⟩，方向相同但层数不同——c_us 是第一层剪切的峰（λ=1），c_ut 是第二层剪切的峰（λ=2）。这正好接上 GPFE：GPFE 曲线上相邻两个峰就是 c_us 和 c_ut。
    2. BCC 的区分口径按 Ojha 2014：滑移路径与孪晶路径分开取鞍点（两者是不同路径的山口，不能互相代替）。
    3. 为什么必须区分："先滑移还是先孪晶"取决于两个势垒的相对高低。c_ut≫c_us 时孪生偏位错形核远难、塑性走滑移；两者接近时孪晶才有机会。

      4. 结论：c_us=滑移路径的山口、c_ut=孪晶路径的山口；两者相对高低决定滑移-孪生竞争。

03-04 为什么 BCC 的 γ 面无稳定极小，这如何导致分数位错

思路（先讲清两问的连接）

两个子问题，按因果顺序答：① 为什么 BCC 无稳定极小——稳定极小意味着存在非零错排让两侧原子"停得住"（存在稳定层错）；FCC {111} 密排面有天然"坑"（错排 1/6⟨112⟩ 落进空位），BCC {112} 非密排没有中间"坑"，能量从 0 单调爬坡到格矢归零。② 这如何导致分数位错——经典分解靠"中间稳定层错"当恒力绳子（两根偏位错弹性排斥↔层错能恒定吸引，有限间距平衡）；BCC 没有绳子，经典平衡间距不存在，错排只能靠 γ 面恢复应力连续铺开，等价于连续 Burgers 矢量密度——这就是分数位错+不稳定层错带。

先备知识

  • 稳定极小：γ 曲面上存在非零错排 f_s，两侧原子"停得住"（恢复应力为零且稳定平衡）——即能存在稳定层错。
  • 分数位错：BCC 芯分解产物，夹不稳定广义层错带、带内层错矢量连续变化（见 01-05）。
  • 经典分解（FCC 范式）：全位错→两根偏位错，中间夹稳定层错；层错能恒定提供吸引力，与两根偏位错的弹性排斥平衡，得到有限间距。

逐步推导

  1. 无稳定极小的原因：稳定极小意味着存在非零错排 f_s 让两侧原子停得住。FCC {111} 密排：错排 1/6⟨112⟩ 时上层原子落进下层空位（C 位），天然停得住。BCC {112} 非密排：相邻层沿 ⟨111⟩ 有 (1/3)⟨111⟩ 固定偏移（01-06），任何非格矢错排都把一部分原子推向正对/近接触位形（反孪生方向最近邻从静止态 0.866a 缩到 0.816a），没有中间"坑"——能量从 0 单调爬坡到格矢处归零。
  2. 因此经典分解在 BCC 不成立：经典分解靠"中间的稳定层错"当恒力绳子——两根偏位错弹性排斥 ↔ 层错能恒定吸引，在有限间距平衡。BCC 没有绳子，经典分解的平衡间距不存在。
  3. BCC 芯怎么铺开错排：托住错排的是 γ 面恢复应力 F(f)=−∇γ(f)。错排连续分布 f(x)，每处 df 相当于一段无穷小位错（分布 Burgers 矢量密度 ρ=df/dx）——这就是分数位错+不稳定广义层错带。

    4. 结论：BCC {112} 面没有稳定层错（无中间"坑"），经典"两根偏位错+稳定层错绳"的分解不成立；芯的错排靠 γ 面恢复应力连续铺开，形成分数位错+不稳定层错带。

03-05 "γ 面是一切的开端吗"——层级关系

思路（先讲清分两层看）

"开端"要分两层：计算工具层（谁算出谁）与理解链条层（物理因果从哪流到哪）。计算上势函数是开端（层错能">γ 面是用势算出来的）；理解链条上真正的上游是 μ⟨111⟩ 与内聚能（它们定 γ 面形貌），γ 面是链条的枢纽——下游每一步都用 γ 面语言说话。

先备知识

  • 势函数：原子间相互作用的数学描述（FS 势等），由晶格常数、弹性常数、内聚能、空位形成能等物性拟合而来。
  • μ⟨111⟩：⟨111⟩ 方向剪切模量；内聚能：把晶体拆散成自由原子所需的能量。

逐步推导

  1. 计算工具层：最上游输入是势函数。γ 面本身用势函数算出，所以计算上 γ 面不是开端——势函数才是。
  2. 理解链条层（物理因果）：起点是 μ⟨111⟩ 剪切模量（定 γ 曲线小位移斜率）与内聚能（定峰值）→ γ 面形貌（含肩部）→ 芯结构（分数位错分解、刃分量、对称性）→ Peierls 应力 → 本征各向异性 → 反孪生不对称" title="孪生-反孪生不对称">孪生-反孪生不对称。
  3. γ 面是理解链条的枢纽：下游每一步都用 γ 面语言说话；势函数只是算 γ 面的手段，不参与理解链条。

    4. 结论：计算上势函数是开端；理解链条上 μ⟨111⟩+内聚能→γ 面→芯→Peierls→不对称，γ 面是枢纽。

03-06 自测 Q12：c_us/c_ut 为什么必须区分

思路：两个鞍点分属两条路径；区分它们是为了量化滑移-孪生竞争——混成一个数就失去预测"材料会不会孪晶"的能力。

逐步推导

  1. 定义对：滑移路径与孪晶路径是两个不同的鞍点（03-03）。
  2. 缺的一层：区分它们是为了量化滑移-孪生竞争——c_ut≫c_us 时滑移占优，两者接近时孪晶才能与滑移竞争。
  3. 混成一个数就失去预测"材料会不会孪晶"的能力。

    4. 结论：两个鞍点分属两条路径，相对高低决定塑性走滑移还是走孪晶。

03-07 自测 Q14：Zhang 2011 为什么必须验高压 γ 面

论文来源：Zhang et al., "Twinning in BCC Metals under Shock Loading: A Challenge to Empirical Potentials", *Philosophical Magazine Letters* 91 (2011) 731–740. DOI: 10.1080/09500839.2011.615348。
前置条件：研究对象 Nb 单晶（五种势：3 EAM + 2 FS），唯一冲击方向 [110]；检验高压（数十 GPa）下 {112} 广义层错能曲线。

思路（先讲清逻辑链）

冲击孪晶发生在几十 GPa 高压下 → 孪晶路径的能垒由高压下 {112} γ 面决定 → 经验势只在零压拟合数据附近可靠、高压行为是外推 → 外推可能错。所以验势必须验高压段的 γ 面：出现人为亚稳态的势会算出假相变（bcc→fct），只验零压不够。Zhang 2011 的五势对比就是这个逻辑的执行。

先备知识

  • 冲击孪晶发生在几十 GPa 高压下。
  • 经验势由零压（或低压）物性拟合，高压行为是外推——外推可能错。
  • 孪晶路径的能垒由 γ 面决定（03-01）。

逐步推导

  1. 冲击孪晶发生在几十 GPa 高压下 → 孪晶路径的能垒由高压下 {112} γ 面决定 → 势函数只在零压拟合数据附近可靠、高压行为是外推 → 外推可能错。
  2. Zhang 2011 拿 Nb 单晶算了五种势（3 EAM+2 FS，唯一冲击方向 [110]）：零压下五种势的广义层错能都相近且正确。
  3. 加压到数十 GPa 后，其中三种势的 {112} γ 曲线多出人为局部极小（本不该有的亚稳态）→ MD 走 bcc→fct 相变而非孪晶。
  4. 只有 A.MFS 与 F.EAM 复现高压实验孪晶。
  5. 结论：冲击孪晶 MD 前必须把势函数的高压 {112} γ 曲线与 DFT 对照，出现人为亚稳态的势直接淘汰；只验零压不够。

    6. 结论：高压 γ 面是冲击孪晶模拟的判据——人为亚稳态的势会产生假相变；验势必须验高压段。

04-01 为什么三层是 zonal 最小单元，1-2 层为什么不行

主要来源：Li et al., "Deformation twinning in body-centered cubic metals and alloys", *Progress in Materials Science* 139 (2023) 101160. DOI: 10.1016/j.pmatsci.2023.101160（§5.1–5.2）；晶体学/机制口径另见 Lagerlöf 1993（zonal）与 Mahajan 1972（3n 层错）。

思路（先立判据，再逐层淘汰）

"三层是 zonal 最小单元"这句话要检验两个词："三层"为什么成立、"最小"为什么卡在三层。策略：先把"孪晶胚成立"拆成两个独立判据，再让 1、2、3 层各过一遍筛——① 堆垛判据：该区域必须变成母体的镜像堆垛（"孪晶"定义的要求）；② 闭合判据：累计位移必须回到格矢，否则错排区域边界不闭合（"晶格自洽"的要求）。逐层验：1 层先倒（单层层错能是全位错的 1.6–9.4 倍、本征不稳定，判据②还没到就过不去）；2 层净位移 2×(1/6)⟨111⟩=1/3⟨111⟩ 不是格矢、不闭合；3 层净位移 3×(1/6)⟨111⟩=1/2⟨111⟩，恰是 BCC 的晶格平移矢量、闭合，且三层内完成镜像翻转。两个判据同时在 3 层满足——"最小"的意思就是"同时过两关的最小层数"，所以 1-2 层不行不是能量一条理由，是两条判据各淘汰一层。结论的物理意义：3 层累计位移 1/2⟨111⟩ 正是 zonal 里螺位错自己的 Burgers 矢量，zonal 与三层结构天然同源。

先备知识

  • 孪晶=母体关于 (112) 面的镜像；要成立，{112} 层堆垛序必须翻转成镜像。
  • 堆垛闭合条件：累计位移必须回到格矢（否则错排区域边界不闭合）。
  • 单层孪晶层错的能量代价：1/6⟨111⟩ 剪切后的单层层错能是全位错层错能的 1.6–9.4 倍，本征不稳定。

逐步推导

  1. 孪晶要求 {112} 层堆垛序翻转成镜像——靠 1/6⟨111⟩ 偏位错" title="孪生位错">孪生偏位错逐层剪切实现（01-03）。
  2. 单层：只平移一层，产生"单层错排"，不是镜像对应；且单层层错能是全位错的 1.6–9.4 倍、本征不稳定（单层孪晶从未被实验观察）。
  3. 两层：净位移 2×(1/6)⟨111⟩=1/3⟨111⟩，不是格矢、不闭合，同样不是镜像。
  4. 三层：净位移 3×(1/6)⟨111⟩=1/2⟨111⟩，恰好是晶格平移矢量——堆垛在 3 层内完成镜像翻转并且闭合。位移闭合回格矢 + 堆垛成镜像的最小单元=三层孪晶胚（zonal）。
  5. 实验支撑：Mahajan 1972 观察"清晰层错=3n 层厚孪晶"——只有 3n 层层错稳定可见。

    6. 结论：1 层不稳定、2 层不闭合，3 层同时满足"闭合（1/2⟨111⟩ 格矢）+ 镜像翻转"，是 zonal 晶体学口径的最小单元。

    口径边界："3 层"是 zonal 晶体学/机制口径；能量稳定性口径下最小稳定厚度是 3–6 层依材料（04-02）。两者不混用。

04-02 最小稳定厚度为什么是 3–6 层（GPFE 能量口径）

思路（先定"量尺"，再查数）

本问的"最小稳定厚度"是能量口径，与 04-01 的 zonal 晶体学口径不是同一把尺。策略：第一步把能量判据说清——GPFE 曲线 γ(λ) 是逐层剪切的能量曲线（03-02），第一个稳定振荡点就是"再多一层不会自发退回来"的最小层数，这正是本问要的量尺；第二步把库内已核验的各来源数值逐个放到这把尺上比（Vítek 1970 n≥3、Ojha Fe-50Cr 3 层、Ogata Mo 6 层、Zhang DFT 高压 3 层/零压 6 层、W 原位 6 层≈0.77 nm、modified Orowan 模型 n*≈8α/3τb 代 W 值得 n*≈5→6 层）；第三步收口：3 层只对 Fe-Cr/高压成立，Mo/W 是 6 层，所以"三层最小"是 zonal 口径、"3–6 层"是 GPFE 能量口径，引用时必须写明用的是哪把尺。

先备知识

  • GPFE 曲线 γ(λ)：逐层剪切的能量曲线；第一个稳定振荡点=最小稳定厚度（03-02）。

逐步推导

  1. GPFE 曲线 γ(λ) 的第一个稳定振荡点决定最小稳定厚度。
  2. 各来源数值（Li 2023 综述行 811–855 原文核验）：

    3. - Vítek 1970：n≥3 层稳定；

    - Ojha：Fe-50Cr 的 γut 在 3 层以上稳定；

    - Ogata：Mo 从 6 层开始稳定；

    - Zhang DFT：高压 3 层、零压 6 层；

    - W 原位实验：as-nucleated twin 最小 6 层（≈0.77 nm，22 根纳米线统计）；

    - modified Orowan 模型：n*≈8α/3τb，代入 W（τ≈9 GPa、α=1482 mJ/m²、b=0.0909 nm）得 n*≈5 → 最小稳定 6 层，与实验一致。

    1. 所以"三层最小"只对 Fe-Cr/高压成立；Mo/W 是 6 层。

      2. 结论：最小稳定厚度=GPFE 第一个稳定振荡点，依材料 3–6 层（Mo/W 6 层）；与 zonal 的"3 层"是两个口径，引用时注明。

04-03 反孪生是什么、为什么难、两层交错剪切量为什么是 1/4

思路（一个问题拆三段：是什么 → 为什么难 → 1/4 怎么来）

三个小问共享一条逻辑链，先讲清楚再上数。第一段"反孪生是什么"：孪生方向 η₁=[1̄1̄1] 确定后，反孪生就是它的反向剪切。方向取反要写全三分量过程：η₁=[1̄1̄1]=(−1,−1,1) 整体取反 =(1,1,−1)=[111̄]，横线只落在第三个分量——这就是 −η₁。先自检两个方向都在 (112) 面内：[1̄1̄1]：1·(−1)+1·(−1)+2·1=−1−1+2=0 ✓；[111̄]：1·1+1·1+2·(−1)=1+1−2=0 ✓。第二段"为什么难"：用 01-06 的原子几何作对照实验——同一套静止位形（相邻 {112} 层沿 ⟨111⟩ 偏移 −(1/3)[1̄1̄1]），看两个剪切终点各把原子推向什么环境：孪生终点 u=2/3 回到 0.866a 密排环境，反孪生终点 u=0 正对下一排原子、最近邻压到 0.816a——阻力差距就从这两个终点位形比出来。第三段"1/4"：把 Xie 2024 两条反孪生路径各算一遍"每层平均剪切量"——逐层模式每层 2b_p=1/3⟨111⟩；两层交错模式每双层净位移 +b_p、平均每层 b_p/2；两个平均量一除 (b_p/2)÷(2b_p)=1/4。所以 1/4 不是晶体学常数，是"交错路径相对逐层路径的每层平均位移比"，对应能垒 282 vs 417 mJ/m²。

先备知识

  • 孪生方向 [1̄1̄1]、反孪生方向 −η₁=[111̄]（取反三分量 (−1,−1,1)→(1,1,−1)、横线只落在第三个分量），都在 (112) 面内（点积自检见上文思路段；另见 01-06/10-05）。
  • 原子几何结论（01-06，图谱 v31 修正版）：相邻 {112} 层沿 ⟨111⟩ 偏移 −(1/3)[1̄1̄1]，静止位形在周期 1/3 处；孪生剪切终点 2/3（路径中点 0.924a、终点回 0.866a 密排环境）；反孪生剪切终点 0（正对下一排原子，0.816a 压缩）。

逐步推导

  1. 反孪生定义：{112} 面沿 ⟨111⟩ 有两个相反剪切方向。孪生方向（+η₁）把晶格映射成低能镜像孪晶；反孪生方向（−η₁）把原子推向近接触/重叠位形，必须靠 shuffle 辅助，阻力远高。根源是 {112} 面沿 ⟨111⟩ 的方向各向异性。
  2. 为什么难（原子几何）：相邻 {112} 层沿 ⟨111⟩ 偏移 1/3 周期；反孪生剪切把上层原子推向 u=0——正对下一排原子，最近邻从 0.866a 压缩到 0.816a，路径上原子迎面接近；孪生剪切把原子推向 u=2/3——与静止位形对称等价，回到 0.866a 密排环境（路径中点 0.924a 只有轻微鞍部）。
  3. 实验基准：Guiu 1969，Mo 77 K 反孪生 CRSS 约是孪生的 1.5 倍。
  4. 两层交错剪切量=1/4（Xie 2024，库内已核验）：两条反孪生路径——逐层反孪生每层滑 2b_p=1/3⟨111⟩（Ta 能垒 417 mJ/m²）；两层交错每双层"−b_p 一层 + 2b_p 一层"=净位移 +b_p（能垒 282 mJ/m²）。剪切量比值=(b_p/2)÷(2b_p)=1/4。
  5. 注意两个"逐层"的区别：反孪生语境的"逐层模式"是剪切路径（每层 2b_p）；"孪晶按 3 层一组增厚"是形核/增厚的稳定性口径，两回事。单层孪晶不稳定说的是形核胚；已有 ≥3 层孪晶的界面可以每过一根 1/6⟨111⟩ disconnection 逐层迁移。

    6. 结论：反孪生难在原子几何（推向正对位形 0.816a）；两层交错路径净位移只有逐层模式的 1/4、能垒更低（282 vs 417 mJ/m²），是反孪生更可行的路径。

04-04 zonal 重复弓出是什么机制

思路（先认"弓出"的力学，再把 zonal 对号入座）

"重复弓出"三个词要逐个落实。策略：第一步回顾两个零件——zonal 是什么（1/2⟨111⟩ 螺位错在三个相邻 {112} 面分解出的三根共线 1/6⟨111⟩ 偏位错，整体运动）和弓出的力学（Peach-Koehler 力 F=τb 推位错线段弯曲扫面，两端被约束就是 Frank-Read 源几何，02-08）。第二步把两者拼起来：一次弓出=三根 1/6⟨111⟩ 同时扫过三个相邻面=留下三层孪晶片，这就是把"留下一道滑移台阶"换成"留下三层孪晶片"；复位后再次弓出=再扫接下来三个面 → 3、6、9…（3n 层）离散增厚，W 实测每步 0.41 nm=3 层。第三步回答"为什么不需要极轴"：极轴机制靠一根不动轴位错让偏位错螺旋扫动、每圈铺一层；zonal 三根并排、一次平面扫动铺三层，重复弓出本身就是铺层方式，螺旋与 sessile 轴都省掉（Lagerlöf 1993）。

先备知识

  • zonal=1/2⟨111⟩ 螺位错在三个相邻 {112} 面分解出的三个共线 1/6⟨111⟩ 偏位错，整体运动。
  • Peach-Koehler 力 F=τb：切应力 τ 作用在位错上单位长度的力。
  • Frank-Read 源：两端钉扎的位错段反复弓出、放环（02-08）。

逐步推导

  1. 单个 1/6⟨111⟩ 扫过一层=该层从母体变孪晶；三个同时扫=一次产生三层孪晶。
  2. 弓出：位错线段在切应力下受 Peach-Koehler 力 F=τb，两端被约束（连着母螺位错线/结点）时弯曲成弧扫面——Frank-Read 源几何。
  3. zonal 的弓出把"留下一道滑移台阶"换成"留下三层孪晶片"；复位后再次弓出，扫过接下来的三个面，又+3 层 → 3、6、9…（3n 层）离散增厚（W 实测每步 0.41 nm=3 层）。
  4. 为什么不需要极轴：极轴机制用"一根偏位错绕不动轴螺旋、每圈铺一层"；zonal 是"三根并排、一次平面扫动铺三层"，重复弓出就是它的铺层方式，螺旋和 sessile 轴都被省掉（Lagerlöf 1993）。

    5. 结论：zonal 用 Frank-Read 式重复弓出实现 3n 层离散增厚——一次弓出+3 层、复位再弓出，无需极轴。

04-06 滑移与孪生的定义与区别

思路（先定一把尺子，再量两个对象）

滑移与孪生容易混，策略是先用"扫过之后母体取向变不变"作总判据——这是两者最根本的分界，然后看各自如何过这把尺：滑移（全位错平移格矢=结构复原、偏位错平移小于格矢=留层错）扫过后取向都不变；孪生逐层累计 1/6⟨111⟩ 剪切，使扫过区域取向翻转成镜像。判据立起来后，其余三个区别（载体、切变量、启动条件）都是它的推论，逐一对照列出。最后一步防混淆：区别不在"全位错 vs 偏位错"上——偏位错滑移也是滑移；孪生位错">孪生偏位错滑移同时是滑移（位错在动）和孪生（取向翻转），两者不是互斥分类。

先备知识

  • 取向：晶格的三个基矢朝向；取向不变=扫过区域还是原晶体；取向翻转=变成镜像晶体。

逐步推导

  1. 滑移：位错沿滑移面运动，扫过后晶体两部分相对平移一个 Burgers 矢量。全位错滑移=平移格矢=结构复原；偏位错滑移=平移小于格矢=留层错——两者母体取向都不变。判据：取向不变。
  2. 孪生：孪生偏位错在相邻 {112} 面逐层滑移，每层平移 1/6⟨111⟩，累计结果是该区域取向翻转成镜像。判据：取向翻转。
  3. 区别四条：载体（全位错 b=格矢 vs 孪生偏位错 b<格矢）、扫过后（取向不变 vs 翻转）、切变量（不固定 vs 固定 s=1/√2）、启动条件（克服 Peierls 应力 vs 先形成 3–6 层临界胚）。
  4. 区别不在"全位错 vs 偏位错"上——偏位错滑移也是滑移；孪生偏位错滑移既是滑移（位错在动）又是孪生（取向翻转）。

    5. 结论：滑移的判据是取向不变、孪生的判据是取向翻转；载体、切变量、启动条件随之不同。

04-07 滑移一个不全位错就是形成孪晶了吗

思路（把问题拆成"是不是"与"都出吗"两半）

这句话半对半错，策略是把句子拆成两半分别检验。前半"滑移一个孪生位错"：对——孪生就是孪生位错在滑移，1/6⟨111⟩ 扫过一层把该层变成孪晶层；但要补"一层不够"：BCC 单层孪晶不稳定（GPFE λ=1 是峰），稳定要 3–6 层，所以只滑一个全位错" title="不全位错">不全位错是孪生的一步、不是孪晶。后半"任何一个不全位错"：错——偏位错不一定是孪生位错，FCC 的 Shockley 偏位错滑一层留层错、取向不变，那是滑移；要它旁边一层再滑一个偏位错才出两层微孪晶。两半合起来收口：孪生位错滑一层=孪生的一步，但不是所有偏位错滑移都出孪晶。

先备知识

  • 孪生位错 1/6⟨111⟩：扫过一层把该层变成孪晶层。

  1. 对一半：孪生偏位错滑移一层，确实把那一层变成孪晶层——孪生就是"孪生位错在滑移"。
  2. 但要补两点：

    3. - 一层不够：BCC 里单层孪晶不稳定（GPFE λ=1 是峰），稳定孪晶要 3–6 层。"滑移一个不全位错"只是孪生的一步。

    结论：孪生位错滑一层=孪生的一步；但不是所有偏位错滑移都出孪晶（Shockley 滑移只留层错）。

04-08 "c_us 低→位错滑移→才能孪晶"这个链条对吗

思路（链条切两段，每段独立验）

"c_us 低→位错滑移→才能孪晶"是一条三段链条，策略是切成两段分别检验、最后给出修正后的正确链条。第一段"c_us 低→位错容易滑移"：基本对，但要补环节——c_us 压低的是滑移偏位错形核势垒，形核后能不能动另看 Peierls 应力，所以链条上要加"形核"二字。第二段"位错能滑移→才能生成孪晶"：在 BCC 对（Mahajan 1972：slip must precede twinning；Sleeswyk 1963：孪晶胚由 1/2⟨111⟩ 螺位错分解而来），滑移位错是孪晶形核的原料。但把整条链读成"c_us 低→孪晶多"就错了，两个理由：孪晶形核要的是孪生位错">孪生偏位错、势垒是 c_ut，c_us 管不着；滑移与孪晶抢同一份塑性，c_us 很低时塑性全被滑移消耗，孪晶反而没机会。收口给正确链条：c_us 低→滑移位错多（原料足）；c_ut 与临界胚决定孪晶能否启动；c_ut≈c_us 时孪晶才能与滑移竞争。

先备知识

  • c_us：滑移偏位错形核势垒；c_ut：孪生偏位错形核势垒（03-03）。
  • 位错变形分两步：形核（过 c_us 山口）与运动（过 Peierls 应力）。

逐步推导

  1. 分两段检验。第一段"c_us 低→位错容易滑移"基本对，但要补环节：c_us 压低的是滑移偏位错形核势垒；形核后能不能动看 Peierls 应力。
  2. 第二段"位错能滑移→才能生成孪晶"在 BCC 对：Mahajan 1972（slip must precede twinning）+ Sleeswyk 1963（孪晶胚由 1/2⟨111⟩ 螺位错分解而来）——滑移位错是孪晶形核的原料。
  3. 但"c_us 低→孪晶多"不成立，两个理由：① 孪晶形核需要孪生偏位错，势垒是 c_ut，c_us 管不着；② 滑移与孪晶抢同一份塑性，c_us 很低时塑性全被滑移消耗，孪晶反而没机会。
  4. 孪晶占优条件是 c_ut≈c_us（两者接近）；c_us 单独低只说明滑移容易。
  5. 正确链条：c_us 低→滑移位错多（原料足）；c_ut 与临界胚决定孪晶能否启动；两者接近时孪晶才能与滑移竞争。

    6. 结论：链条第一段对（补"形核"二字）、第二段对；但"c_us 低→孪晶多"错——孪晶启动由 c_ut 与临界胚决定，条件是 c_ut≈c_us。

04-09 孪晶生长的尖端就是位错芯吗

思路（先立两个对象，再比数量，再给边界情形）

策略：先各自立定义——孪晶尖端是什么（前沿界面）、位错芯是什么（一根线的芯），然后回答"尖端=芯吗"：关键在数量与结构层次——尖端是一个界面结构，位错芯是一根线的芯。最后给边界情形（最薄孪晶）与尖端其他活动（发射位错），并补 Li 2024 的两种生长模式的尖端结局。

先备知识

  • 孪晶尖端：孪晶片与基体的前沿界面（graph-data.js node=e-twin-front）——孪晶片长度方向的终止边界，由相继 {112} 面上的孪生位错列对齐构成，即非共格孪晶界（ITB）。
  • 位错芯：位错线周围弹性解失效的非线性畸变区（02-01/02-09）。
  • 孪生位错 1/6⟨111⟩：扫过一层 {112} 面把该层转成孪晶层，骑在孪晶界上=单层 disconnection（05-05）。

逐步推导

  1. 尖端的构成（Li 2024 原文，Nat Commun 15:560，译文 line 48）：生长中孪晶胚的前缘由相继 {112} 面上对齐排列的偏位错" title="孪生位错">孪生偏位错组成，形成非共格孪晶界（ITB）——每一根孪生位错都带自己的芯（~1 nm 非线性畸变区）。

  3. 原位细节（Li 2024 图 1）：孪晶尖端处上方 CTB 上孪生偏位错成簇（每簇约 0.4 nm=3 个相继原子台阶，对应三个 (112) 孪生偏位错）——尖端附近不止一根、而是成簇的位错芯。
  4. 边界情形：若孪晶胚极薄（如 Xiao 2023 裂纹尖端 2 层胚的引导构型，10-09），尖端畸变集中区贴着那根（或那几根）孪生位错的芯——"尖端附近=孪生位错芯区"近似成立；一般厚度下尖端是多根芯的集合。

    7. 结论：孪晶尖端是承载孪生位错芯的界面结构（ITB）；"尖端=位错芯"只在把尖端简化为一根孪生位错（最薄孪晶/单根台阶）的极限下近似成立，一般情况下尖端是许多根位错芯的集合（原位观察为每簇 3 根的成簇排列）。

    # 05 · disconnection 与界面（从基础概念讲起版）

    本版说明：每问按「先备知识 → 逐步推导 → 结论 → 口径边界」重写，符号先定义再使用；数值与归因不变。相关图谱节点：e-disconnection、e-csl、e-reciprocal-lattice、e-dsc、e-twin-boundary、e-ctb、e-tb-reflection、e-tb-isosceles、e-pseudo-coherent-tb、e-twin-front；文件 entity-disconnection.md。

05-01 disconnection 的定义（直觉式）

思路（从熟的位错走到生的界面缺陷）

定义题的策略是"从已知搭桥"：disconnection 与位错共享同一个定义套路——绕一圈回路不闭合的量。先把位错的定义骨架讲清（晶体内部、Burgers 回路比对完美晶格），再把宿主从"晶体内部"换成"界面"：换宿主之后多出什么、又少了什么——多出"台阶 h"（界面在缺陷线两侧错开的高度，以面间距计，这是界面特有、晶内没有的量）；"位错内容 b"依旧有，但回路现在画在双晶里、闭合失败量必须属于 DSC 晶格（05-04）。两个量捆绑、各自沿界面线守恒、不可分离，这就是 disconnection。最后给实例收口（BCC {112} CTB 的单层/双层/三层三个成员），并说明 b=0 是位错内容消失的退化情形（纯台阶）。

先备知识

  • 位错：晶体内部"绕一圈回路不闭合"的线缺陷，用 Burgers 回路比对完美晶格定义。
  • 界面：孪晶界/晶界——分隔两晶体的面。
  • DSC 晶格：把双晶图样整体平移后图样不变的全部平移组成的格子（05-04）。

逐步推导

  1. disconnection 是界面上带台阶的位错。用最基础的类比：位错是晶体内部"绕一圈回路不闭合"的线缺陷；disconnection 是同一种东西，宿主换成界面——它是孪晶界/晶界内部的一条线缺陷，携带两个捆绑的量：

    2. - 台阶 h：界面在缺陷线两侧错开的高度，以界面面间距计；

    - 位错内容 b：绕缺陷线一圈的 Burgers 回路在双晶中的闭合失败量，必须属于 DSC 晶格。

    1. 特性：b 与 h 各自沿界面线守恒、不可分离；沿线保守滑移，界面随之沿法向迁移 h，一层晶体转化为另一层；b=0 是位错内容消失的退化情形（纯台阶）。
    2. 实例（BCC {112} CTB，Wei 2024）：单层 b=1/6⟨111⟩、h=1 层（=孪生位错在界面上的身份）；双层 b=1/6⟨111⟩ 反向、h=2 层；三层 b=0、h=3 层。

      3. 结论：disconnection=界面上"台阶 h+位错内容 b（∈DSC）"双守恒的线缺陷；滑移使界面迁移 h。

05-02 为什么宿主必须是双晶界面

思路（追着两个概念要宿主）

策略是顺着定义里的两个词往下追，看它们各自把宿主逼到哪：先追"台阶"——台阶是界面在缺陷线两侧错开的高度，"错开一层"这个概念只在界面上有意义，单晶内部没有界面就没有台阶，所以宿主必须是界面；再追"层转化"——disconnection 滑移的后果是"一层晶体 λ 变晶体 μ"（孪晶增厚/减薄），两侧是同一种晶体就无所谓转化、那条缺陷就退化成普通位错，所以界面必须隔开两种晶体。两条各追一步，链条就是：台阶 ⟹ 界面 ⟹ 双晶。

先备知识

  • 台阶：界面在缺陷线两侧的高度错开——这个概念只在界面上有意义。
  • 晶内位错的滑移后果：两侧晶体相对平移 b，母体取向不变。

逐步推导

  1. disconnection 定义里有"台阶"→"台阶"概念只在界面上存在（单晶内部没有界面、没有"界面错开一层"这回事）。
  2. 界面必须隔开两种晶体：disconnection 滑移的后果是"一层晶体 λ 变晶体 μ"（孪晶增厚/减薄）——两侧同一种晶体就不存在转化，那条缺陷就是普通位错。
  3. 所以链条是：台阶 ⟹ 界面 ⟹ 双晶。

    4. 结论：台阶概念迫使宿主是界面，层转化的后果迫使界面两侧是两种晶体。

05-03 为什么 b 必须是 DSC 矢量

思路（反证法立局域性，再用构造正面验证）

策略是两步。第一步反证：线缺陷的硬要求是局域性——畸变随离缺陷线距离增大而衰减，不能延伸到无穷远。假设 b 取非 DSC 矢量，回路两侧远处的界面就彼此错开一个破坏重合结构的矢量，这个错开沿界面延伸到无穷远、畸变不再局域——矛盾，所以 b 只能取"对双晶不可见"的平移，即把 CSL 映到自身的平移，也就是 DSC 晶格的全部矢量。第二步正面构造：b=t(λ)−t(μ)（孪晶晶格平移减母体晶格平移），按 DSC 的定义它自然落在 DSC 里；再用 1/6[1̄1̄1]=1/3[112]−1/2[111] 实例验证（右侧两项分别是两晶格的平移矢量，其差正是孪生位错的 b）。正反两条路汇到同一个结论。

先备知识

  • b 的定义：绕缺陷线画 Burgers 回路，回路在远离线的完好区域走，闭合失败量=b；回路画在双晶里，穿过两侧两种晶体。
  • 线缺陷的局域性要求：畸变必须随离缺陷线距离增大而衰减，不能延伸到无穷远。

逐步推导

  1. 反证：若 b 不是 DSC 矢量——回路两侧远处的界面就彼此错开一个破坏重合结构的矢量；这个错开沿界面延伸到无穷远，畸变不再局域，缺陷就不再是线缺陷。
  2. 所以 b 只能取"对双晶不可见"的平移=把 CSL（重合结构）映到自身的平移=DSC 晶格的全部矢量（DSC 的构造见 05-04）。
  3. 构造上自然如此：b=t(λ)−t(μ)——孪晶晶格平移与母体晶格平移之差，按定义落在 DSC。实例验证：1/6[1̄1̄1]=1/3[112]−1/2[111]（右侧两项分别是两晶格的平移矢量，其差就是孪生位错的 b）。

    4. 结论：b 取非 DSC 矢量会把界面错开延伸到无穷远、破坏线缺陷的局域性；b∈DSC 是局域性的强制要求。

05-04 CSL 与 DSC"互为倒格子"是什么意思

思路（先各自构造，再用定理相连）

策略分三步。第一步构造 CSL：孪晶与基体两套格点按取向关系叠画成双色图，两晶格重叠后的公共格点组成重合位置点阵——{112}⟨111⟩ 孪晶对应 Σ3，重合点密度 1/3、CSL 元胞=3×晶胞，是稀疏超格子。第二步构造 DSC：保持整个双色图不变的所有平移组成全平移晶格——Σ3 时元胞=1/3×晶胞，含 1/6⟨111⟩、1/3⟨112⟩ 这类分数矢量，是比原晶格还细的子格子。两个格子一个粗一个细。第三步用 Grimmer 1974 定理把两者连起来：DSC=CSL 的倒格子，体积乘积 V_CSL×V_DSC=V_晶胞²——"互为倒格子"说的就是这层粗细互逆关系。最后翻译到物理用处：倒格子定义 g·R=2π×整数 翻到实空间就是"DSC 矢量把 CSL 格点平移到 CSL 格点"（保持重合结构），这正是 05-03 要求 b∈DSC 的几何理由。

先备知识

  • 倒格子：晶格 L（格矢 R）的倒格子 L* 由所有满足 g·R=2π×整数（∀R∈L）的矢量 g 构成；晶格越粗倒格子越细，元胞体积乘积为常数。
  • 双色图：孪晶与基体两套格点按取向关系叠画、两色区分（10-06）。

逐步推导

  1. CSL（重合位置点阵）=两晶格重叠后公共格点构成的骨架。{112}⟨111⟩ 孪晶对应 Σ3：重合点密度=1/3，CSL 元胞=3×晶胞——稀疏超格子。
  2. DSC（全平移晶格）=保持整个双色图不变的所有平移组成的格子。Σ3 时元胞=1/3×晶胞，含 1/6⟨111⟩、1/3⟨112⟩ 这类分数矢量——细密子格子（比原晶格还细，见 10-06 的红蓝图平移验证）。
  3. Grimmer 1974 定理：DSC=CSL 的倒格子（互为倒格子）。粗 CSL ↔ 细 DSC，V_CSL×V_DSC=V_晶胞²。
  4. 物理用处：倒格子定义"g·R=整数"翻译到实空间="DSC 矢量把 CSL 格点平移到 CSL 格点"（保持重合结构）——这正是 disconnection 的 b 必须 ∈DSC 的几何理由（接 05-03）。

    5. 结论：CSL 与 DSC 一个粗一个细、互为倒格子；"DSC 矢量保持 CSL 不变"是 b∈DSC 的直接表述。

05-05 孪生位错为什么就是单层 disconnection

思路（三步核对：住哪 → 带什么 → 合不合定义）

策略是对照 disconnection 的定义逐条核。第一步看宿主：孪生位错 1/6⟨111⟩ 扫过一层 {112} 面后，"母体|孪晶"分界正好落在刚扫过的那层——它天然住在孪晶界上，宿主条件满足。第二步数它携带的量：台阶 h=1 层（界面前进一个面间距）、位错内容 b=1/6⟨111⟩（该层剪切量）。第三步对照三条件：b∈DSC（05-03 已验证 1/6[1̄1̄1]=1/3[112]−1/2[111]）、有台阶 h、在界面上滑移——三条件全满足。结论收口：同一物理对象两种称谓，站在"晶内 {112} 面滑移"视角叫孪生位错，站在"界面缺陷 (b,h)"视角叫单层 disconnection，宿主从晶内滑移面换成界面，对象没换。

先备知识

  • 孪生位错 b_p=1/6⟨111⟩：在 {112} 面滑移，扫过之处该层从母体取向转到孪晶取向。

逐步推导

  1. 孪生位错扫过一层后，"母体|孪晶"分界正好位于刚扫过的那层——所以它天然住在孪晶界上（扫过之处就是界面）。
  2. 数它携带的量：台阶 h=1 层（界面前进一个面间距）；位错 b=1/6⟨111⟩（该层剪切量）。
  3. 对照 disconnection 定义三条件：b∈DSC（05-03 已验证 1/6[1̄1̄1]=1/3[112]−1/2[111]）+ 台阶 h + 在界面上滑移——三条件全满足。
  4. 同一个物理对象两种称谓：站在"晶内 {112} 面滑移"视角叫孪生位错；站在"界面缺陷 (b,h)"视角叫单层 disconnection。宿主从晶内滑移面换成界面，对象没换。

    5. 结论：孪生位错扫过一层就把界面推进一层——它就是 h=1 层、b=1/6⟨111⟩ 的单层 disconnection。

05-06 三层 disconnection 为什么 b=0，b=0 为什么叫特例

思路（两问分开：b=0 是构型结果，"特例"是分类用语）

本问两个"为什么"性质不同，分开答。第一问"为什么 b=0"：是构型计算的结果——把三层看成单层（+1/6⟨111⟩、1h₀）与双层（−1/6⟨111⟩、2h₀）的复合，b 相加 +1/6⟨111⟩−1/6⟨111⟩=0 精确相消、台阶相加 3h₀；原子图景是迁移后第三层原子回到原位（正负剪切抵消）、第一二层做 shuffling；后果是 b=0 不产生宏观应变（原文 zero-macroscopic-strain twin disconnection），纯剪切对它无 Peach-Koehler 力、只能在耦合载荷下整体驱动（原文摘要）。注意旧版"净平移 3×1/6⟨111⟩=1/2⟨111⟩ 被格矢吸收"是错误推理、已弃用。第二问"为什么叫特例"：是分类学用语——disconnection 的普遍成员 b≠0（既带台阶又带位错），b=0 是位错内容消失的退化极限，类似 0 是整数的特殊成员；它不表示三层增厚罕见，三层恰恰是 3n 离散增厚的正常单元。"物理上常见"与"分类上退化特例"是两回事。

先备知识

  • Peach-Koehler 力 F=(σ·b)×ξ：应力对位错的作用力；b=0 时力为零。
  • 3n 离散增厚：孪晶按三层一组增厚（04-01）。

逐步推导

  1. 为什么 b=0（Wei 2024 原文构型）：三层=单层（+1/6⟨111⟩、1h₀）与双层（−1/6⟨111⟩、2h₀）的复合——b 相加 +1/6⟨111⟩−1/6⟨111⟩=0 精确相消，台阶相加 3h₀。
  2. 原子图景：迁移后第三层原子回到原位（正负剪切抵消）、第一二层做 shuffling。
  3. 后果：b=0 不产生宏观应变，原文称 zero-macroscopic-strain twin disconnection；纯剪切对它无 Peach-Koehler 力，只能在耦合载荷下整体驱动（原文摘要）。
  4. 旧版"净平移 3×1/6⟨111⟩=1/2⟨111⟩ 被格矢吸收"是错误推理，已弃用。
  5. b=0 为什么叫特例：分类学用语——disconnection 普遍成员 b≠0（既带台阶又带位错），b=0 是位错内容消失的退化极限，类似 0 是整数的特殊成员。它不表示三层增厚罕见；三层恰恰是 3n 离散增厚的正常单元。"物理上常见"与"分类上退化特例"是两回事。

    6. 结论：三层 b=0 来自单层与双层的精确相消；"特例"是分类学用语，三层增厚本身是常规单元。

05-07 disconnection 与 kink 的区别

思路（先各自立名，再三维对照）

策略是先把两个对象各用一句话立住，再用三个维度对照收口。kink：位错线在滑移面内的局部弯折（02-05），是几何扰动、无自身拓扑内容、热涨落成对生灭。disconnection：界面上"台阶 h+位错内容 b（∈DSC）"的复合缺陷，b/h 双守恒、不可分离，是孪晶界迁移的载体。三个维度逐条比：宿主（晶内位错线 vs 界面）、拓扑内容（无自身 b、无台阶 vs b 与 h 双守恒）、守恒律（热涨落成对生灭 vs 沿界面线守恒）。两者是不同宿主下的不同对象，不因"都叫缺陷"而可互换。

先备知识

  • kink：位错线在滑移面内的局部弯折（02-05）。

07-01 为什么位错线方向用周期边界、垂直方向用自由表面+外层固定

前置条件：研究对象是一根无限长直位错（螺位错：位错线 ξ=[111]、Burgers 矢量 b=1/2[111]，两者平行），放在有限大小的模拟盒子里。
先讲三个基础概念，再看两个解释。

思路（抓住位错的两个特点，各配一种边界）

策略是从位错本身的物理出发，而不是从"软件选项"出发：一根无限长直位错有且只有两个麻烦的特点——① 它是一条线（不能有端点，端点=露在表面的线头=像力拉拽）；② 它的畸变延伸很远（1/r 衰减太慢，远处不能有副本，否则副本位错会干扰它）。先把支撑这两个特点的基础概念立住（边界条件是什么、像力是什么、长程弹性场是什么），然后让每种边界条件各解决一个特点：轴向周期边界解决①（首尾相接、没有线头），径向自由表面+外层按理论解固定解决②（没有副本、远场交给弹性公式）。最后用 DV98 的圆柱算例（直径 32a、内区 931 原子弛豫、外层弹性位移场固定）证明这不是孤例。

概念 1：边界条件是什么

MD 只能放有限个原子，而我们要研究的是"无限大晶体里的一根无限长位错"。盒子里的原子到了边界处，会问一个问题："我外面是谁？"边界条件就是对这个问题的回答。两种最基本的回答：

  • 周期边界：把盒子无限复制、铺满整个空间。盒子右侧的原子把"左边盒子里对应位置"的原子当邻居；原子从右边出去，就从左边回来。这样盒子里的原子感觉自己处在一个无限大的晶体里。
  • 自由表面边界：盒子边界就是真的边界，外面是真空。边界上的原子只受盒子内部邻居的力，可以自由移动——这就是一块真实材料的表面的样子。

概念 2：像力是什么

位错是一根线，线周围的原子偏离完美位置（畸变）。如果这根线露在自由表面上，线头附近的表面就要同时满足两个要求：既要容纳位错带来的畸变，又因为是自由表面而可以随便变形。结果表面会局部变形来"适应"线头。这个表面变形反过来对位错线施加一个力，把它往表面方向拉或推。物理上，这个效果等价于：在表面的另一侧对称位置虚构一个"镜像位错"，镜像位错对真实位错的作用力就叫做像力。像力会移动位错、改变它的形状——于是你模拟的对象就从"晶体内部一根自由的位错"变成"被表面拉着走的一根位错"。

概念 3：长程弹性场是什么

位错周围每个原子偏离完美位置的位移，随它离位错线的距离按 1/r 慢慢衰减。关键在"慢"：离位错线几百个原子的地方，位移仍然明显。这种延伸到很远的畸变分布，就是位错的长程弹性场。它有一个重要性质：在离芯几纳米以外的地方，这个场可以用弹性力学公式精确算出来（各向异性弹性理论），只有芯附近几纳米的区域公式失效、必须逐原子算。

解释一：轴向周期边界——解决"线不能有端点"

位错是一根线。真实晶体里的直位错是无限长的；但模拟盒子是有限的。如果位错线沿盒子的上下方向穿出去，它就在盒子的上下两个表面上终止了——线头露在表面。

线头露在表面的后果：按概念 2，两个线头处产生像力，位错被表面拉拽、芯结构被扭曲。你研究的就变成"一根被两个表面钳住的短位错"。

解决办法：让位错线沿盒子的一个方向（纵轴）放置，这个方向用周期边界。周期边界让盒子首尾相连：位错线在盒子顶端"出去"，从底端"回来"，线头接上线尾，变成一条没有端点的线。没有端点 → 不接触任何自由表面 → 没有像力。这就是"轴向周期边界让位错首尾相接、没有端部自由表面"的意思。

解释二：径向自由表面 + 外层固定——解决"远处不能有副本"

位错的长程畸变延伸到很远（概念 3）。如果垂直于位错线的两个方向也用周期边界，盒子被无限复制后，每个副本里都有一根位错，它们排成整齐的阵列、彼此只隔一个盒宽。由于畸变延伸得很远，每根位错都"感觉到"旁边无数个副本位错的畸变场、受到它们的力。你研究的就变成"位错阵列"，单根位错的芯结构被相邻副本扭曲了。

解决办法分两半：

  1. 径向用自由表面：垂直方向有真的表面，位错旁边没有副本。
  2. 自由表面自己也会产生像力（概念 2），怎么办：把盒子做大，然后把最外一圈原子钉死——钉在"无限晶体中一根无限长位错"的理论解给出的位置上（概念 3 的弹性公式可以算出离位错任意距离的原子该在什么位置），不让这一圈原子松弛。于是内区原子看到的邻居全部处于"无限晶体+无限长位错"应有的位置，内区原子自己松弛出来的就是正确的芯结构。

    3. 这相当于：把一个无限大的系统切一个窗口出来研究，窗口边缘按理论公式固定住；内区只有芯附近几纳米需要逐原子算（那里公式失效），外面全交给公式。

    一句话串起来

    位错线有两个特点：它是"一条线"（不能有端点），它的畸变"延伸很远"（远处不能有副本）。轴向周期边界解决第一个问题（首尾相接、没有线头），径向自由表面+外层按理论解固定解决第二个问题（没有副本、远场由公式代替）。

    同源做法：DV98 算螺位错芯用圆柱（直径 32a、内区 931 原子弛豫、外层按各向异性弹性位移场固定），与本条逻辑完全相同。

07-02 为什么采用圆柱模型研究单一位错行为（Hou 2025）

论文来源：Jie Hou, Ducheng Peng, Xiang-Shan Kong, Huiqiu Deng, Wangyu Hu, Cheng Chen, Jun Song, "Hydrogen modulated dislocation reaction and defect accumulation in bcc metals", *Acta Materialia* 301 (2025) 121524. DOI: 10.1016/j.actamat.2025.121524（§2.2）。
前置条件：模拟对象是 BCC Fe 中一根孤立位错（研究 H 对位错线能量的影响）；盒子是半径 150 Å、厚约 20 Å 的圆柱，位错线沿纵轴，径向自由表面、轴向周期边界，外层 7 Å 固定、内区自由弛豫。

思路（三个理由，各自对应圆柱的一个几何要素）

策略是拿 07-01 的两个特点当检查清单，逐条看圆柱模型怎么满足，再补圆柱形状独有的第三个理由：① 位错线是无限长直线——轴向周期边界让线首尾相接、没有端部自由表面（否则线头像力扭曲芯）；② 弹性场沿径向长程衰减——径向周期边界会让位错与自己的周期镜像相互作用，所以径向改自由表面+外层固定弹性位移，等于给内区一个"无限晶体远场"；③ 圆柱形状本身——位错的各向异性弹性位移场绕线近似轴对称，圆柱均匀包裹位错线、避免方盒角部人为应力集中；且式 (1) 的线能量要在截断半径 R 内求和，圆柱边界保证"半径 R 以内"这个区域处处定义一致。三条合起来，圆柱是这组边界条件的最自然形状。

先备知识：07-01 的三个概念（边界条件、像力、长程弹性场）与式 (1) 线能量定义：

E_i(R)=(1/L)·Σ_{r_i<R}(E^dis_{i,Fe}−E⁰_Fe)——L 为沿纵轴的位错线长度，E^dis_{i,Fe} 为截断半径 R 内第 i 个 Fe 原子的势能，E⁰_Fe 为完美晶格参考势能。

  1. 位错线是无限长直线：轴向周期边界让位错首尾相接、没有端部自由表面（端部表面会给线头像力、扭曲芯结构）。
  2. 位错弹性场沿径向长程衰减：径向若用周期边界，位错会与自己相邻周期镜像相互作用（周期像力），芯失真；自由表面+外层固定弹性位移，等于给内区一个"无限晶体远场"。
  3. 圆柱形状最均匀：位错的各向异性弹性位移场绕线近似轴对称，圆柱均匀包裹位错线，避免方盒角部的人为应力集中；且式 (1) 定义线能量时要在截断半径 R 内求和，圆柱边界保证"半径 R 以内"这个区域处处定义一致。

    4. 结论：圆柱=轴向周期（无限长线）+径向自由表面+外层固定（无副本、远场由弹性解代替）；圆柱形状保证轴对称与"半径 R 内求和"的定义一致。

07-03 自由表面边界条件是什么

思路（先一句话立住，再对照，再看论文里的分工）

定义题的策略：先用最朴素的语言说清自由表面是什么——边界就是真的边界、外面是真空，表面原子只受体内邻居的力、可以自由弛豫（离开完美格点、表面轮廓自由演化），这模拟的就是真实自由表面（如纳米线表面）。立住之后做一步对照，把最容易混的周期边界摆出来比（周期=盒子无限复制、原子跨边界镜像衔接；自由表面=外面真空、没有衔接）。最后落到 Hou 2025 的具体分工：轴向周期（模拟无限长位错线）、径向自由表面+外层 7 Å 固定（既保留"表面可弛豫"的物理、又防止表面整体漂移或大规模弛豫干扰内区位错）——"自由表面+外层固定"不是自相矛盾，是各管一层。

先备知识

  • 周期边界：盒子被无限复制、原子跨边界镜像衔接（07-01 概念 1）。
  • 像力与长程场：07-01 概念 2、3。

逐步推导

  1. 自由表面=边界处原子没有任何镜像约束：表面一侧是真空，表面原子只受体内邻居的力、可以自由弛豫（离开完美格点位置、表面轮廓自由演化），模拟真实自由表面（如纳米线表面）。
  2. 与周期边界的区别：周期=盒子被无限复制、原子跨边界镜像衔接；自由表面=边界就是真的边界、外面真空。
  3. Hou 2025 里的分工：轴向周期（模拟无限长位错线），径向自由表面+外层 7 Å 固定（防止自由表面整体漂移或大规模弛豫干扰内区位错，同时保留"表面可弛豫"的物理）。

08-02 结合自由能 2.89 eV/Å 超过 ΔE 1.27 eV/Å——全套推导

思路（四步：定义→符号→可比性→物理内容，最后对账）

两个数能不能直接比、比出来说明什么，策略分四步走。第一步把两个量各自的定义钉死：ΔE 是无 H 时形成结的代价（式 (3)：E₃−(E₁cosθ₁+E₂cosθ₂)，全体系最大 1.27 eV/Å>0=不利）；F^H_b 是 H 的结合自由能（式 (2)：nμ_H−(E^dis+H_tot−E^dis_tot)，=把 n 个 H 从远场稀溶液储层搬进位错系统释放的自由能，⟨001⟩ 刃位错 102.4 appm 时 2.89 eV/Å）。第二步解决符号：F^H_b 是"释放量"、定义成正数，进能量账时要带负号（−2.89 eV/Å）。第三步解决可比性：两者都是"单位位错线长的能量变化"（eV/Å），可以直接相加减。第四步交代物理内容：E^dis+H_tot−E^dis_tot 混着 H–Fe 作用、H–H 作用、Fe 重排三项，不是"H 携带的能量"。最后对账：+1.27−2.89=−1.62 eV/Å<0——形成结+H 偏聚的净过程能量下降，H 把不利的结变成热力学有利产物。

先备知识

  • 线能量 E_i(R)=K_i·ln(R/r_c)+E_i^c：单位长度位错线的能量（K_i 为弹性常数因子、R 为截断半径、r_c 为芯半径、E_i^c 为芯能）。
  • 化学势 μ_H：H 在稀溶液储层中每个原子的能量。

逐步推导（四步）

第 1 步：两个量各自的定义

  • ΔE——无 H 时形成结的代价（式 (3)）：

ΔE = E₃ − (E₁cosθ₁ + E₂cosθ₂)

下标 1、2 指两根 ⟨111⟩/2 螺位错，3 指反应产物 ⟨001⟩ 刃位错；θ₁、θ₂ 是它们与结的夹角（投影到结方向）。ΔE>0 表示形成结抬高了总线能量——所以无 H 时反应不利。全体系算下来最大 ΔE=1.27 eV/Å。

  • F^H_b——H 的结合自由能（式 (2)）：

F^H_b = nμ_H − (E^dis+H_tot − E^dis_tot)

三个量：E^dis_tot=没有 H 时系统的总势能（Fe+位错）；E^dis+H_tot=加入 n 个 H 原子后整个系统的总势能；nμ_H=这 n 个 H 原子如果留在远场（化学势 μ_H 的稀溶液储层）应携带的能量。

F^H_b=（H 在远场的能量）−（H 进入系统的能量变化）=把 n 个 H 从远场搬进位错系统，整个系统释放的自由能。H 喜欢待在位错处（那里能量更低）→ 第二项小于第一项 → F^H_b>0，这个正数度量"释放了多少"。对 ⟨001⟩ 刃位错，102.4 appm 时 F^H_b=2.89 eV/Å。

第 2 步："折扣"的符号问题

F^H_b 定义为正数，因为它度量"释放量"，不是"账本记录"。释放能量=能量下降=对线能量的贡献是 −2.89 eV/Å。所以"折扣"进账时带负号——直觉上折扣是负数，完全正确。

第 3 步：为什么两者可以直接比较

两边都是"单位位错线长的能量变化"（eV/Å），可以相加减：

过程线能量变化
无 H 时形成 ⟨001⟩ 刃位错结（ΔE）+1.27 eV/Å（要付的账）
H 偏聚到结上（F^H_b=2.89 的贡献）−2.89 eV/Å（释放的能量）
净变化+1.27 − 2.89 = −1.62 eV/Å

净变化为负=总过程（形成结+H 偏聚）能量下降=热力学有利。论文原话："the binding free energy effectively indicates the H-induced reduction in the line energy"——结合自由能越大，H 引起的线能量下降越大；2.89>1.27，下降盖过上升，结从不利变有利。这就是"H 使本来不利的 ⟨001⟩ 刃位错变成热力学可形成产物"的核心论证。

第 4 步：E^dis+H_tot − E^dis_tot 严格是什么

它是加入 n 个 H 原子后整个系统的能量变化，不是"H 实际携带的能量"。系统总势能是所有原子一起算的，这个差混着三项：① H 与 Fe 的相互作用能；② H 与 H 之间的相互作用能；③ Fe 原子因 H 插入而重新排列引起的能量变化。

结论：ΔE=+1.27（不利账）、H 结合释放 −2.89、净 −1.62 eV/Å——H 的偏聚把不利的 ⟨001⟩ 结变成热力学有利产物。

09-02 Frank 环与 Shockley 偏位错是什么，为什么 BCC 没有

思路（先逐个构造对象，再追共同前提，最后看论文怎么用）

策略是先把两个对象各自完整构造出来（这样"BCC 没有"才有靶子），再找出它们的共同存在前提，最后落到 Hou 2025 的用法。构造一：偏位错" title="Shockley 偏位错">Shockley 偏位错=FCC 全位错 1/2⟨110⟩ 分解成的两根 1/6⟨211⟩ 型偏位错，b 位于 {111} 面内、可滑移（glissile），扫过后把 A 位原子推到 B/C 位、两偏位错之间夹一片内禀层错。构造二：Frank 环=FCC 空位盘在 {111} 面塌缩成的位错环，边界 b=1/3⟨111⟩ 垂直于 {111} 面（纯刃、sessile），环内夹内禀层错（faulted loop）；"去层错"=环内形核 Shockley 偏位错扫过环面，1/3⟨111⟩+1/6⟨211⟩→1/2⟨110⟩ 变完美环。两个对象的共同立足点都是"稳定层错"——Shockley 偏位错夹的是稳定内禀层错、Frank 环的存在意义就在环内的层错。BCC 没有稳定层错，所以两者在 BCC 都不存在：BCC 的对应物是夹不稳定层错带的分数位错；BCC 空位塌缩直接形成完美环、没有 Frank 环中间态。最后看论文用法：Hou 2025 引这条理由（引文 [65]）论证 ⟨001⟩ 空位环稳定（08-05）。

先备知识

  • 稳定层错是这两个对象的存在前提（FCC 层错能">γ 面有亚稳极小）。
  • BCC 无稳定层错（γ 面无亚稳极小，03-02）。

逐步推导

  1. Shockley 偏位错：FCC 全位错分解产物，1/2⟨110⟩→1/6⟨211⟩+1/6⟨12̄1⟩ 型，b 位于 {111} 面内、可滑移（glissile）；滑过后把 A 位原子推到 B/C 位、产生一片堆垛层错，两根之间夹内禀层错。
  2. Frank 环：FCC 空位盘在 {111} 面塌缩形成的位错环，边界 b=1/3⟨111⟩、垂直于 {111} 面（纯刃、sessile），环内夹内禀层错（faulted loop）。去层错=环内形核 Shockley 偏位错扫过环面，Frank 环变完美环（1/3⟨111⟩+1/6⟨211⟩→1/2⟨110⟩）。
  3. 为什么 BCC 没有：两者都以稳定层错为存在前提，而 BCC 无稳定层错。BCC 的对应物是夹不稳定层错带的分数位错；BCC 空位塌缩直接形成完美环，没有 Frank 环中间态、没有去层错。
  4. Hou 2025 用这条理由（引文 [65]）论证 ⟨001⟩ 空位环稳定（08-05）。

    5. 结论：Shockley 偏位错与 Frank 环都靠"稳定层错"立足；BCC 没有稳定层错，所以两者在 BCC 都不存在。

10-01 MD 用了全部方向周期边界？位错之间不会有干扰吗？

思路（先立三个概念，再逐条化解两个"干扰"疑点）

策略：先把三个基础概念立住（周期边界把盒子六面接起来模拟无限晶体；镜像=盒外复制品与真身通过弹性场相互作用；裂纹 MD=中心埋裂纹看尖端长出什么），然后针对提问里的"干扰"分两层化解：第一层是裂纹与自己的镜像之间的干扰——用几何比 a/W（裂纹半长/盒子半宽）量化，论文的解析修正式 (3)(4) 表明 a/W<0.1 时修正因子 f→1、镜像可忽略；第二层是位错之间的干扰——本题在本文根本不存在，因为盒子初始没有预置位错，孪晶/位错都是加载中从尖端现场形核的。最后补一般原则（胞越小缺陷越多镜像干扰越严重，三对策）与一个反面教材（Cai 2004 固定边界 0.5 GPa vs 周期边界 25 MPa，差 20 倍），把"本文为什么成立"和"别的论文怎么判断"都覆盖。

先备知识

  • 周期边界：模拟盒六面接起来，原子从右边出去就从左边回来——用有限盒子模拟"无限晶体"。
  • 镜像：周期复制意味着盒外还有一模一样的复制品（你的缺陷的"影子"），影子与真身通过弹性场互相作用（像力）。
  • 裂纹 MD：在盒子中心埋一条裂纹，加载后看裂纹尖端长出什么（孪晶/位错/解理）。

逐步推导

  1. 本文的盒子：x∥⟨111⟩、y∥[112]、z∥⟨11̄0⟩，尺寸 40×25×2 nm，裂纹长 2a=5.2 nm 埋在中心，三个方向都是周期边界，加载沿 y（ε_yy 每次加 0.001，再用共轭梯度弛豫到能量最小——是 0 K 准静态，不是有限温度动力学）。
  2. 周期边界把盒子接起来 → 你模拟的其实不是"一条裂纹"，而是"无限多条裂纹排成的阵列"。
  3. 阵列里每条裂纹都感受到相邻镜像裂纹的应力场 → 干扰大小由几何比 a/W（裂纹半长/盒子半宽）决定。
  4. 论文用解析修正处理这个干扰（式 (3)(4)）：K_I^p = 2σ₀√W·sin(πa/2W)/√sin(πa/W) = f(a,W)·K_I；当 a/W<0.1 时 f→1（镜像可以忽略）。本文 a/W 很小，所以镜像干扰可忽略。
  5. 关于"位错之间干扰"：盒子初始没有预置任何位错——孪晶和位错都是加载过程中从裂纹尖端现场形核的，形核之前不存在位错相互作用问题；形核之后尖端附近的相互作用是真实物理（尖端局域化），不是边界假象。
  6. 一般原则（判断其他 MD 论文用）：胞越小、缺陷越多，镜像干扰越严重。对策三选一：① 加大胞（Zepeda-Ruiz 2017 用到 2.68 亿原子）；② 位错偶极子/阵列排布抵消长程应力；③ 解析修正因子（如本文）。
  7. 反面教材（库内）：Cai 2004——Mo 刃位错 Peierls 应力，固定边界算 0.5 GPa，周期边界收敛后只剩 25 MPa，差 20 倍。边界条件处理不当，结论可以直接报废。

    8. 结论：三方向周期边界在本文成立，因为 (a) 体系无预置位错、(b) a/W 足够小使镜像修正 f→1。

10-02 d 带是什么？怎么影响孪晶形成？

思路（先立定义，再追"d 带→孪生"链条能走到哪一步）

策略：先把 d 带与 ΔE 的定义立住（d 带=d 轨道电子能带，过渡金属特征；ΔE=HCP 相对 BCC 基态每原子能量差），再顺着论文的逻辑走——引言先说"这些金属 d 带相似、孪生行为却不同"，即 d 带相似解释不了差异；论文改用一个"能算"的代理量 ΔE：BCC 沿孪生剪切后局部变类 HCP 环境，ΔE 小（Fe/VB）→ RC 路径上出现类 HCP 亚稳层错（孪晶胚）→ 孪生容易；ΔE 大（Mo/W）→ 无亚稳谷 → 难。合金层面 Re 经 VCA 改价电子浓度调 ΔE。收口给完整链条（d 电子结构→ΔE→亚稳层错→形核），并在口径边界声明：论文没有 d 带态密度层面的逐金属推导，别编。

先备知识

  • 能带：晶体中电子能量的允许区间。d 轨道电子形成的能带就是 d 带。
  • 过渡金属：VB（V/Nb/Ta）与 VIB（Cr/Mo/W）族，价电子部分填充 d 带——这是它们区别于简单金属（sp 电子）的电子结构特征。
  • ΔE：HCP 结构相对 BCC 基态的总能量差（每原子），是本文的定量代理。

逐步推导

  1. 引言先给背景："这些过渡金属共享部分填充的 d 带、晶体结构与许多本征性质，但孪生行为彼此明显不同"——这句话的逻辑是：d 带相似 → 解释不了孪生差异，差异另有来源。
  2. 那差异从哪里来？论文换一个"能算"的量：BCC 沿孪生剪切后局部变成类 HCP 环境（见 10-12），这个类 HCP 相对 BCC 稳不稳，用 ΔE 量。
  3. ΔE 小（Fe、VB 族）→ 沿 RC 滑移路径在 s_c≈0.4b 处出现类 HCP 亚稳层错（2 层孪晶胚，见 10-13）→ 孪生容易。
  4. ΔE 大（Mo、W，≈0.45 eV/atom）→ 路径上没有亚稳谷 → 孪生困难。原文说这条规律"最终具有量子力学电子起源"。
  5. 合金层面：Re 溶质通过改变价电子浓度（VCA 虚晶近似：把价电子数与芯电子赝势按浓度加权平均）改变 ΔE 与 γ 线，从而调控孪生。
  6. 串起来的影响链条：d 电子结构 → HCP 与 BCC 的结构能量差 ΔE → RC 路径上能否出现稳定/亚稳的类 HCP 层错（孪晶胚）→ 孪晶能否形核。

    7. 口径边界：本文没有给出 d 带填充度/态密度层面的逐金属推导（库内 p-dband 节点标"出处待核验"）；Vitek 2004 核验结论是"d 电子方向性键合使芯更窄，但 FS 与 BOP 算的 CRSS 十分接近（0.021 vs 0.024 C₄₄）——方向性键合不直接等同 Peierls 势垒升高"。所以回答"d 带如何影响孪生"时，能说清的只有 ΔE 代理链条，不要编 d 带态密度故事。

    结论：d 带是背景；本文真正的定量代理是 ΔE（HCP−BCC 能量差），ΔE 决定 RC 路径上有没有"类 HCP 亚稳层错"这个孪晶胚。

10-03 广义层错能 γ 线的计算模拟方式？

思路（五步流水线，讲究全在"放开哪些自由度"）

策略：γ 线计算本身是一条五步流水线（建 {112} 平板+真空 → VASP/PBE/PAW 设置 → 选第 6、7 层之间滑移面、方向 x=⟨1̄1̄1⟩ → 逐步位移 Δs=0.04b → 每步优化记能量）。但真正决定数值的不是这五步，而是第六个隐藏变量——每步优化时放开哪些自由度：γ_fix-x-y-z 全固定（刚性剪切）、γ_fix-x 只放 y/z、γ_rc 只固定滑移面紧邻两层的 x（多层弛豫）。三种口径给三条不同的 γ 线，经典 GPFE 看不到孪晶胚、RC 能看到 2 层胚——所以"最小稳定厚度"的口径差（RC 2 层 vs 经典 3–6 层）根源就在这里，引用数值必须带口径。最后补一致性要求：MD 势（XMEAM）的 γ 线要与 DFT 差 <5%。

先备知识

  • 层错能">γ 面：把晶体沿某晶面切开、两半相对滑移矢量 f、再接合，单位面积剩余能量 γ(f)。f 扫一圈就是一张"能量地形图"（γ 面）。
  • γ 线：固定沿 ⟨111⟩ 方向滑移，能量 γ(s) 随滑移量 s 的曲线——γ 面沿 ⟨111⟩ 的一维截线。
  • DFT：第一性原理电子结构计算；VASP=软件，PBE-GGA=交换关联泛函，PAW=赝势。

逐步推导

  1. 建模型：BCC {112} 层平板（纯金属 12 层、合金 16 层）+ 约 15 Å 真空。真空的作用=把平板上下表面隔开，防止上下表面相互作用。
  2. DFT 设置：VASP + PBE-GGA + PAW，截断能 520 eV，k 点线密度 ≤0.2 Å⁻¹，收敛判据 10⁻⁵ eV 与 0.01 eV/Å；Fe、Cr 用自旋极化。
  3. 选滑移面（图 1a 第 6、7 层之间），滑移方向 x=⟨1̄1̄1⟩。
  4. 把滑移面以上全部原子沿 x 逐步位移，步长 Δs=0.04b=0.02⟨111⟩（b=½⟨111⟩ 的模长）。
  5. 每推一步做一次结构优化、记录能量 → 得到 γ(s) 曲线。
  6. 口径差别全在"优化时放开哪些自由度"（三种）：

    7. - γ_fix-x-y-z（全约束）：所有原子固定=刚性剪切（最经典口径）。

    - γ_fix-x（滑移方向约束）：只放开 y、z 优化，滑移方向 x 仍固定。

    - γ_rc（RC 减约束）：只固定滑移面紧邻上下两层原子的 x，其余全部自由度弛豫（多层弛豫）——见 10-13。

    1. 为什么口径重要：经典 GPFE（Li 2023 综述 §5.1–5.2、Ojha 2014）是逐层刚性剪切、不允许层间弛豫 → 看不到孪晶胚；RC 允许多层弛豫 → 能看到亚稳的 2 层孪晶胚。所以"最小稳定厚度"有口径差（RC 的 2 层 vs 经典的 3–6 层），引用数值必须带口径。
    2. 势函数侧：MD 用的 V1（XMEAM）势，其 γ 线（γ_us 等）必须与 DFT 相差 <5%——保证 MD 与 DFT 能量学一致。

      3. 结论：γ 线=逐步剪切+逐步优化+记能量；计算方法本身简单，真正的讲究在"优化时放开多少自由度"。

10-04 图 2 关于孪晶长大的能量分析没看懂

思路（先认坐标与四条线，再逐条对号入座）

策略：图 2 的难点在于四条线混在一起，先立坐标系与四个概念（横轴 s、纵轴 γ；亚稳谷/能垒/孪生反孪生方向），再按"哪条线是什么口径"逐条认：三条 γ 线（绿实=全约束、绿虚=放 y/z、品红实=RC）都是剪切能量账单，区别只在约束口径——全约束不对称无亚稳点、放 y/z 峰值降 17%、RC 在 s_c≈0.4b 出现亚稳谷（2 层胚）；第四条品红虚线不是 γ 线，是从 2 层胚出发的生长分析。然后把生长能垒读出来对比：顺孪生方向 0.031 J/m²（几乎免费）、反方向 0.514 J/m²（17 倍），再与全位错能垒 γ_ud 比高低，最后落到实验判据（⟨001⟩ 压缩激活位错、⟨110⟩ 压缩激活孪生）。

  • 图 2 坐标：横轴=滑移量 s（以 b=½⟨111⟩ 模长为单位）；纵轴=能量 γ（J/m²，单位面积）。
  • 亚稳谷：曲线上局部极小但不是全局最低——"半山腰的坑"。
  • 能垒：从一个极小构型翻到相邻构型要跨越的能量高度。
  • 孪生/反孪生方向：见 10-05。

逐步推导

  1. 图 2 的三条 γ 线都是"沿 {112} 面、沿 ⟨1̄1̄1⟩ 剪切"的能量账单，区别在约束口径：

    2. - 绿实线（γ_fix-x-y-z 全约束）：不对称、无亚稳点、s≈0.55b 处达峰。不对称=孪生/反孪生方向天然不等价（{112} 面 层错能">γ 面的本征性质）。

    - 品红实线（γ_rc）：两端形貌与前两者相似，但在 s_c≈0.4b 处出现亚稳谷；此处结构优化自发形成 2 层孪晶，其超出能量记 γ_2tw；峰值（完整位错形核能垒 γ_ud）进一步降低。

    2. 沿孪生方向生长能垒 = γ_utw-t − γ_2tw = 0.031 J/m²——几乎为零："2 层胚一旦形成，顺着孪生方向长大几乎不费力"。
    3. 沿反孪生方向 = γ_utw-at − γ_2tw = 0.514 J/m²——约 17 倍，几乎不可能反向生长。
    4. 与全位错对比：孪生总垒 γ_utw-t 比 γ_ud 低 16%；反孪生总垒比 γ_ud 高 37%。即孪生方向"孪晶形核+生长比全位错更便宜"、反孪生方向"全位错更便宜"。
    5. 落到实验：沿 ⟨001⟩ 压缩 → (112) 面上分切应力落在反孪生方向 → 激活位错塑性；沿 ⟨110⟩ 压缩 → 分切应力落在孪生方向 → 激活孪生。这与 Fe、Nb、Ta、Cr 单晶实验一致。

      6. 结论：图 2 上半部分=剪切能量账单（γ 线）；品红虚线=2 层胚增厚的能量账单：顺向 0.031 J/m²（几乎免费）、反向 0.514 J/m²（17 倍，几乎不可能）。

10-05 文章中的反孪生方向是什么方向？怎么推理出来？

先备知识

  • 方向在晶面内的判据：hu+kv+lw=0（立方系点积判据，见 10-11）。
  • BCC {112} 面堆垛序：ABCDEF 六层周期。
  • 偏位错 1/6⟨111⟩：孪生剪切的最小"半步"平移。

思路（先讲清要干什么、按什么顺序干）

"反孪生方向"这个词本身已经给了答案的一半：反孪生=孪生剪切的反向，所以反孪生方向就是孪生方向的反方向——只要知道孪生方向，把它整体取反就得到反孪生方向，不用另找。因此推理分三步：① 确认孪生方向 η₁=[1̄1̄1]（这个本体已定，只需复核它确实躺在 (112) 面内）；② 对它整体取反得反孪生方向 −η₁=[111̄]，同样验证它在 (112) 面内——注意取反是三个分量一起变号，横线位置跟着动：(−1,−1,1) 取反得 (1,1,−1)，横线只落在第三个分量上；③ 解释"为什么反方向难"：看沿两个方向剪切后原子落到哪里（正方向落进镜像堆垛、反方向正对下方原子排）。

逐步推导

  1. 孪生方向 η₁=[1̄1̄1]=(−1,−1,1) 在 (112) 面内：(112)·[1̄1̄1]=1·(−1)+1·(−1)+2·1=−1−1+2=0 ✓。
  2. 反孪生方向=η₁ 的反向：−[1̄1̄1]=−(−1,−1,1)=(1,1,−1)=[111̄]。验证在面内：(112)·[111̄]=1·1+1·1+2·(−1)=1+1−2=0 ✓。
  3. 谁叫"孪生方向"？看剪切之后的产物：沿 [1̄1̄1] 剪 1/6⟨111⟩，各层被推进孪晶镜像位置，堆垛变成 …ABA…（低能构型）——所以 [1̄1̄1] 是孪生方向。
  4. 沿反向 [111̄] 剪同样量：把层推向"正对下方原子排"的位置——高能不稳定堆垛（Sleeswyk 1963 称"反常层错"；Lagerlöf 1993：反向一个偏位错=同向两个偏位错，对应高能层错 γ₂）。所以 [111̄] 是反孪生方向。
  5. Wang 2020（Sci. Adv.）的镜像论证版本：反孪生时 E 层原子必须移动 1/3[111̄] 才能成为 C 层原子的镜像，而且 D 层原子正挡在剪切路径下方 → 阻力远高于孪生方向的 1/6 剪切。（Wang 2020 原文观察的是规范系 (112)[1̄1̄1] 的对称等价变体：孪生面 K₁=(1̄12̄)（extract Fig.1 图注 "(1̄12̄) planes along [110]"），[1̄10] 压缩下普通孪生 ⅙[1̄11](1̄12̄)、拉伸下反孪生 ⅓[11̄1̄](1̄12̄)——反孪生与普通孪生在同一孪晶面上、只是剪切方向相反（[11̄1̄]=−[1̄11]），不存在"反孪生面"这个面。）
  6. 本文的定量版本：γ_rc 线不对称——孪生方向（正 s）上升平缓、反孪生方向（负 s）陡峭；从 2 层胚出发反方向生长能垒 0.514 J/m²（vs 孪生方向 0.031 J/m²）→ 所以"所有 5 种孪生元素中反孪生方向的形变孪生都不太可能"。

    7. 结论：反孪生方向=[111̄]（孪生方向 [1̄1̄1] 整体取反：三个分量一起变号，横线只落在第三个分量）；"反"的本质是它把层推向正对下方原子排的高能位置。

    口径边界：本文"反孪生"=沿 −η₁ 从 2 层胚反向生长（结论"几乎不可能"）；Wang 2020 的反孪生=每层 1/3⟨111⟩ 剪切（纳米线超高应力下可发生）；Xie 2024=反孪生经两层交错 shuffling-sliding 低能垒路径。三者对象与结论层次不同，引用时不要混。

10-06 双色图与 DSC 晶格（图 4d）是什么意思？

思路（画图→数重合点→问平移→得格子→落到界面缺陷）

策略：按构造顺序走五步——先把孪晶与基体两套格点按取向关系叠画成双色图（Hirth–Pond 双晶晶体学工具）；再找重合点，重合点排成的格子就是 CSL（{112}⟨111⟩ 孪晶为 Σ3）；然后问关键问题"这张图整体平移哪些矢量后原样归位"，用一个例子验证（沿孪生方向平移 a/6⟨111⟩=一个孪生位错 b，图样不变）；把所有这种平移收集起来，加减封闭构成 DSC 晶格（"displacement shift complete"=挪完原样归位）；最后两步落到用处：解释为什么 DSC 比原晶格细（a/6⟨111⟩ 不是晶格平移、Σ3 时细 3 倍）和为什么 disconnection 的 b 必须 ∈DSC（远处界面须保持重合结构），并给出图 4d 的 δ 角色（δ 改变双色图样→改变 DSC→改变容许的 b 清单）。

先备知识

  • 晶体=格点的周期阵列；界面=两晶体相接的面。
  • 孪晶与基体有固定取向关系（{112}⟨111⟩：绕孪生方向转 180° 的关系）。

逐步推导

  1. 双色图：把孪晶与基体两套格点按实际取向关系重叠画在同一张图里，两色区分。这是双晶晶体学（bicrystallography，Hirth–Pond）的基本工具。
  2. 图上有些位置两套格点完全重合 → 所有重合点又排成一个格子 = CSL（重合位置点阵）。Σ=CSL 元胞体积/晶胞体积；{112}⟨111⟩ 孪晶是 Σ3（每 3 个晶胞体积有 1 个重合点）。
  3. 关键问题：这张双色图整体平移哪些矢量后，图样与原图完全重合？
  4. 验证一个例子：把整个图样沿孪生方向平移 a/6⟨111⟩（正好是一个孪生位错的 b）——图样不变。因为孪晶界两侧的原子排布本来就是以这种错位共存的，再错位一个 a/6⟨111⟩ 还是同一张图。同理 a/3⟨112⟩ 平移也不变。
  5. 把所有满足"平移后图样不变"的矢量收集起来——它们加减之后仍满足该性质，所以构成一个格子 = DSC 晶格。名字 "displacement shift complete" 就是这个意思："挪完了、整个图样原样归位"的位移。
  6. 为什么 DSC 比原来的晶格还细：a/6⟨111⟩ 不是晶格平移（晶格平移是 a/2⟨111⟩ 的整数倍），它比晶格平移还小 → DSC 格点比晶格密；Σ3 时密 3 倍（DSC 元胞=晶胞的 1/3），所以装得下 1/6⟨111⟩、1/3⟨112⟩ 这类分数矢量。
  7. 为什么 disconnection 的 b 必须属于 DSC：绕界面上缺陷做 Burgers 回路，闭合失败量 b 只能是"不扰动远处界面"的平移——因为远离缺陷处界面必须恢复同样的重合结构；若 b 不是 DSC 平移，远处的双色图样就被扰乱了。
  8. 图 4d 在本文的具体含义（δ 的角色）：

    9. - 反射 TB（镜像对称）对应 δ=0。

    - 近等腰 TB=反射构型再沿孪生方向平移一个有限矢量 δ（图 4a→b）。δ 改变了双色图样，从而改变了 DSC 晶格。

    - δ≠0 时，DSC 中平行 TB 的两个最短矢量是 δ 与 b，满足 δ+b=b_t=⟨111⟩/6——这两个矢量就是 TB 上容许的 disconnection Burgers 矢量（图 4d）。

    - δ=0（Mo、W）时，容许的只剩 b_t 一根。

    结论：DSC="把红蓝图整体平移后看起来一模一样"的所有平移组成的格子；界面缺陷的 b 只能从这张清单里拿；δ 决定清单长什么样。

10-07 等腰 TB、近等腰 TB？"近等腰"是啥意思？

思路（从"标准形"出发，逐级引入偏离）

策略：按"标准形→第一种偏离→第二种偏离"的阶梯讲。先立标准形=反射 TB（两侧镜面对称）；第一种偏离=等腰 TB——跨界面三列原子呈等腰三角形、不镜像，等于反射构型+沿孪生方向 1/12⟨111⟩ 刚体平移（Vítek 1970 / Bristowe–Crocker 1975），稳定性用 Shi & Singh 2016 的 γiso/γref 排序（<1 等腰稳：Ta/Nb/Fe；>1 反射稳：Mo/W）；第二种偏离=本文的"近等腰"——DFT 弛豫出的 2 层孪晶界既不精确镜像也不是理想等腰，主体等腰+有限平移 δ+界面畸变，所以加"近"字。最后讲 δ 的用处（改双色图样→改 DSC→改容许 disconnection，接 10-06）与本文数值（Fe 近等腰为基态 0.418 J/m²）。

先备知识

  • 孪晶界=分隔孪晶与基体的界面。
  • 镜面对称：界面一侧是另一侧的镜像。
  • 刚体平移：整体挪动、不改变相对位置。

逐步推导

  1. 反射 TB：孪晶界两侧原子关于界面镜面对称（几何界面=两 {112} 原子面之间的镜面）。
  2. 等腰 TB（isosceles TB）：跨界面取相邻三列原子，其构型呈等腰三角形（一侧原子为顶点、另一侧两原子为底边）——不满足镜面对称。原始出处 Vítek 1970（Scr. Metall. 4:725）与 Bristowe–Crocker 1975 的"位移型界"：等腰界=反射界+沿孪生方向 1/12⟨111⟩ 刚体平移；由相邻 {112} 面上的两根 1/12⟨111⟩ 偏位错组成。
  3. 谁更稳？Shi & Singh 2016 用稳定孪生层错能比 γiso/γref 排序：<1 等腰稳、>1 反射稳。数值：Ta 0.836、Nb 0.939、Fe 0.945、Mo 1.020、W 1.069 → Ta/Nb/Fe 倾向等腰、Mo/W 倾向反射。
  4. 近等腰（near-isosceles，本文术语）：本文 DFT 弛豫出的 2 层孪晶界"不具备镜面反射对称性，而具有近等腰结构，带一个沿孪生方向的有限平移 δ，TB 上有一些畸变"。即：主体构型是等腰型，但附加了一个有限的 δ 平移（且有畸变）——既不是精确镜面、也不是理想等腰，所以加"近"字。
  5. δ 的作用：改变双色图样 → 改变 DSC 晶格 → 改变界面上允许的 disconnection（正是 10-06 图 4d 的那个 δ）。
  6. 本文数值：Fe 中近等腰 TB 是基态（γ_iso-tw=0.418 J/m²，比反射 TB 低 0.03 J/m²）；VB 族基态、Cr 相对反射为亚稳、Mo/W 不稳定。

    7. 结论：等腰=三列原子呈等腰三角形排列（不镜像）；近等腰=等腰主体+有限平移 δ+界面上有畸变——"近"字就是"不理想"的意思。

10-08 偏 disconnection 是啥？

思路（拿已知的"全位错→偏位错"套路套到界面上）

策略：先把两个已知对象立住——disconnection（界面线缺陷，携带台阶 h 与位错内容 b∈DSC，Wei 2024 单元表）与偏位错（全位错拆两根夹层错带，FCC Shockley 是原型）；再把"拆分"套路从晶内搬到界面：完整孪晶 disconnection 的 b_t=⟨111⟩/6 拆成 b=δ 与 b=b_t−δ 两根、中间夹一片 TB 层错——这就是偏 disconnection，与滑移里"全位错→两根偏位错夹层错带"完全同构（本文原文的类比）。然后回答"为什么这么拆有意义"：Fe/VB/Cr 的孪晶界近等腰（δ≠0），迁移由这对偏 disconnection 实现（先扫 δ、再扫 b_t−δ、中间留 TB 层错）；Mo/W 的 δ=0 不拆。最后以 MD 验证收口（V 裂纹模拟观察到一对 δ、b disconnection 夹 TB 层错的生长构型）。

先备知识

  • disconnection（先给定义）：界面上的线缺陷，携带两个捆绑的量——台阶 h（界面在缺陷线两侧的高度错开）与位错内容 b（Burgers 回路闭合失败量，必须∈DSC，理由见 10-06 第 7 步）。它沿界面保守滑移，界面随之沿法线迁移一个台阶高度。（Wei 2024 单元表：单层 b=1/6⟨111⟩ 与 h₀；双层反向与 2h₀；三层 b=0 与 3h₀。）
  • 偏位错：全位错拆成两根、中间夹层错带（FCC Shockley 偏位错夹内禀层错是原型）。

逐步推导

  1. 孪晶界上的"完整"孪晶 disconnection：b_t=⟨111⟩/6。
  2. 偏 disconnection（本文用法）：把这根完整 disconnection 拆成两根——b=δ 与 b=b_t−δ，两根之间夹一片 TB 层错（能量 γ_tbsf）。这跟滑移中"全位错→两根偏位错夹层错带"完全同构（本文原文的类比就是 FCC Shockley 偏位错夹内禀层错）。
  3. 为什么这么拆有意义：Fe/VB 族/Cr 的孪晶界是近等腰的（δ≠0），其迁移由这对偏 disconnection 实现——先扫一根（b=δ）、再扫另一根（b=b_t−δ），中间留一片 TB 层错。
  4. Mo/W 中 δ=0：TB disconnection 的 b 直接等于 b_t（不拆分）。
  5. 本文的 MD 验证（V 裂纹模拟）观察到孪晶生长正是"一对 δ、b disconnection 夹 TB 层错"。

    6. 结论：偏 disconnection=把孪生 disconnection 的 b_t 拆成 δ 与 b_t−δ 两根、中间夹 TB 层错；它是近等腰孪晶界迁移的载体。整个过渡金属家族因此分成两类：Fe 系"一对偏 disconnection+TB 层错"、Mo/W"单根 b_t disconnection"。

10-09 为什么这个裂纹尖端的孪晶是两层的？

思路（在能量景观上找"第一个能站住的坑"）

策略：把"为什么是两层"翻译成能量景观问题——从薄往厚数，第一个稳定/亚稳构型是几层？第一步排除 1 层（GPFE λ=1 是局部极大，1 层立不住）；第二步看 RC 路径（V/Fe/VB/Cr）在 s_c≈0.4b 处出现的亚稳谷=2 层胚（近等腰 TB 基态）——这就是能量景观的第一个"坑"；第三步对号入座：裂纹尖端恰好制造 RC 场景（剪切局域在两三层原子、其余弛豫），形核的自然产物就是第一个坑=2 层胚；第四步解释"尖端 2 层、后面多层"：2 层胚顺孪生方向生长能垒仅 0.031 J/m²，一形成就迅速增厚。最后口径边界收口：与 zonal 三层最小单元不矛盾（不同约束路径），Mo/W 对照（连 2 层亚稳谷都没有）。

先备知识

  • 层错：堆垛序局部错了。
  • GPFE 曲线 γ(λ)：层错能">γ 面概念沿层数方向的推广——第 λ 层被剪后单位面积能量随 λ 的变化。
  • RC 场景：剪切只局域在少数几个原子层内、其余区域自由弛豫（10-13）。

逐步推导

  1. BCC 没有稳定的单层孪晶层错：剪 1 层（λ=1）在 γ(λ) 曲线上是局部极大（Vítek 1968；Ogata 2004）→ 1 层立不住。
  2. 那第一个"能站住"的构型是几层？在 V（以及 Fe、VB 族、Cr）中，沿 RC 路径在 s_c≈0.4b 处出现亚稳谷——2 层孪晶是第一个稳定/亚稳单元（2 层胚+近等腰 TB 是基态结构）。
  3. 裂纹尖端恰好制造 RC 场景：剪切变形局域在两三层原子内、其余区域弛豫（图 5b）→ 所以形核的自然产物就是能量景观里的第一个"谷"=2 层胚。
  4. 2 层胚沿孪生方向生长能垒仅 0.031 J/m²（10-04）→ 一形成就迅速长成多层——这就是图 5c"尖端 2 层、后面多层"的原因。临界载荷处（ε_yy=4.55%）孪晶核的尖端由 2 层孪晶结构引导（与 RC 方法的 2 层胚完全相同）。
  5. 对照 Mo/W：连 2 层亚稳谷都没有，需要"两个连续滑移面各滑 0.33b"的直接 3 层路径 → 更难孪生。

    6. 结论：2 层是 RC 能量景观的第一个"坑"；裂纹尖端恰好是 RC 场景，所以先出 2 层胚，随后顺着 0.031 J/m² 的低垒迅速增厚。

    口径边界：这与知识库"三层 zonal 最小单元"不矛盾——zonal 三层是螺位错三重分解路径的最小单元，RC 路径的最小单元是 2 层；两者是不同约束路径下的结果，引用时注明口径。

10-10 displacement 和 dislocation 的区别是什么？

思路（一个量"动了多少"、一个判据"回路闭不闭合"，分开立再连）

策略：两个词拼写相近、概念不同层，先各自立定义——displacement 是位移矢量场 u(x)（任何变形都有，全场相同=刚体平移不产生缺陷）；dislocation 是晶格线缺陷，判定标准=绕线一圈 Burgers 回路闭合失败量 b≠0。再讲两者的联系：位错的位移场有"多值性"——绕线一圈回来差一个 b（弹性解里的 arctan 项）。然后给判断口诀：看位移多大没用、看回路闭不闭合（DDM 三列微分位移闭路和=b）。最后落到本文用法：RC 施加 displacement → 优化 → 生成含 dislocation 的孪晶结构。

先备知识

  • 位移：位置变化量（矢量）。
  • Burgers 回路：绕缺陷走闭合圈，与完美晶格同一圈比对，闭合失败量=b。

逐步推导

  1. displacement（位移）：原子相对参考位置移动了多少——矢量场 u(x)。任何变形（弹性、剪切、整体平移）都有位移；全场相同的均匀位移=刚体平移，不产生任何缺陷。
  2. dislocation（位错）：晶格中的线缺陷，判定标准=绕线一圈的 Burgers 回路闭合失败量 b≠0（拓扑对象，携带 b）。
  3. 两者的联系：位错的位移场有"多值性"——绕位错线一圈回来，位移差了一个 b（位移场的奇异性）。弹性解里 u 含 arctan 项就是它的数学表现。
  4. 判断口诀：看"位移多大"没用，看"回路闭不闭合"。DDM 图中三列原子的微分位移（相邻列位移差）闭路和=b/3×3=b——这才是位错存在的判据；单看某一列的位移是 b/6、b/3 都说明不了问题。
  5. 本文中的用法：RC 方法施加位移 Δs 于滑移面上方原子（人为剪切）；结构优化后原子自己找到的稳定构型是 2 层孪晶——孪晶界上的台阶即孪生位错。所以流程是"施加 displacement → 优化 → 生成含 dislocation 的孪晶结构"。MD 裂纹模拟同理：加载的位移场在裂纹尖端局域化，达到临界值时形核出孪晶（含孪生位错/偏 disconnection）。

    6. 结论：displacement 是"动了多少"（一个场）；dislocation 是"绕一圈回不到原点"（一个缺陷）。前者是过程量，后者是产物；本文的路线是施加前者、得到后者。

10-11 裂纹、位错的晶向晶面如何确定？晶向坐标系怎么确定？

思路（先立坐标系，再定记号规则，再给判据与实例，最后讲实验）

策略：一切指数都定义在"坐标系"上，所以第一步立坐标系（晶体学坐标=晶胞三基矢，BCC 用惯用立方晶胞）；第二步定记号规则（[uvw] 负分量加横线、(hkl) 截距倒数互质）；第三步给两个捷径与一个判据——立方系 (hkl) 法线=[hkl]、方向在面内 ⇔ hu+kv+lw=0，并用孪生要素实例验算（K₁=(112)、η₁=[1̄1̄1]：−1−1+2=0 ✓）加一个反例（[111]·(112)=4≠0，η₂ 属于 K₂ 不要求在 K₁ 内）；第四步补晶带轴与叉积；第五步讲实验怎么定（SAED 斑矢量=倒格矢、斑距反比面间距、观察方向=带轴）；最后落到本文坐标约定（x∥⟨111⟩、y∥[112]、z∥⟨11̄0⟩，验证两两正交）。

先备知识

  • 基矢：晶胞的三条棱矢量 a₁、a₂、a₃。
  • 倒格矢：与晶面垂直的矢量（晶面族的法线方向）。

逐步推导

  1. 坐标系：晶体学坐标=晶胞三基矢 a₁、a₂、a₃。BCC 用惯用立方晶胞（体心立方，三基矢正交等长 a，沿 x/y/z）。所有指数都在这套基上定义。
  2. 晶向 [uvw]：矢量 u·a₁+v·a₂+w·a₃；负分量上加横线（如 [1̄1̄1] 表示 (−1,−1,1)）。
  3. 晶面 (hkl)：在三个轴上截距为 a₁/h、a₂/k、a₃/l 的平面（h、k、l 互质）。面法线∝倒格矢 h·b₁*+k·b₂*+l·b₃*；立方系倒格矢与正格矢平行，所以立方系里 (hkl) 的法线就是 [hkl]（六方系不适用此捷径）。
  4. 判方向是否在面内：方向在面内 ⇔ 方向垂直于面法线 ⇔ 点积为零 ⇔ hu+kv+lw=0（立方系点积判据）。
  5. 实例：孪生要素 K₁=(112)、η₁=[1̄1̄1]：(112)·[1̄1̄1]=1·(−1)+1·(−1)+2·1=0 ✓ 在面内。反例：[111] 与 (112)：1+1+2=4≠0，[111] 不在 (112) 内（η₂=[111] 属于 K₂=(1̄1̄2) 面，本就不要求在 K₁ 内）。
  6. 晶带轴：一组平面的公共方向 [uvw]（组内所有 (hkl) 满足 hu+kv+lw=0）；两平面的交线=两法线的叉积；两方向的公垂面=两方向的叉积（作面法线）。
  7. 实验上怎么确定：衍射（SAED）——斑点到中心斑的矢量是倒格矢，两斑叉积给出带轴（观察方向）；斑距反比于面间距。TEM 里观察方向=带轴，所以能直接说"沿 [110] 观察"。
  8. 本文的坐标约定（图 5a 裂纹模型）：x∥⟨111⟩（滑移方向）、y∥[112]（裂纹面 (112) 的法线）、z∥⟨11̄0⟩（裂纹前沿）。验证正交：z·y=(−1)·1+1·1+0·2=0 ✓、z·x=−1+1+0=0 ✓——三轴两两正交，是合法的正交坐标系。

    9. 结论：晶向晶面都在晶胞基矢坐标系里定义；"晶向在晶面上"的判据=点积 hu+kv+lw=0；实验靠衍射斑（倒格矢）定面与方向。

10-12 HCP 结构是什么？

思路（先讲结构本身，再讲它与孪晶的关系）

策略：先回答"是什么"——HCP=密排面 ABAB 两层周期堆垛的六方结构（参数：a=b≠c、γ=120°、理想 c/a=√(8/3)≈1.633、配位数 12、每晶胞 2 原子），与 FCC 的区别只在堆垛序（ABAB vs ABC）；再回答"和孪晶什么关系"——BCC 的 {112} 面堆垛序是 ABCDEF 六层，沿 ⟨111⟩ 剪 1/6⟨111⟩ 后局部原子环境变成类 HCP（ABAB 式，原文强调非精确 HCP）；于是 HCP 相对 BCC 的能量差 ΔE 成为孪晶形核难易的代理——ΔE 小（Fe/VB）易孪生、大（Mo/W≈0.45 eV/atom）难；溶质（Re 降 ΔE）与温度（ΔG=ΔE−TΔS）是推广。

先备知识

  • 堆垛：密排原子层一层一层怎么叠。

逐步推导

  1. HCP（六方密排）：密排面按 ABAB 两层周期堆垛的六方结构——密排面内原子呈正六角排列，第三层原子回到第一层正上方。
  2. 晶格参数：a=b≠c、α=β=90°、γ=120°；理想轴比 c/a=√(8/3)≈1.633；配位数 12；每晶胞 2 原子。代表：Mg、Zn、Cd、Ti、Zr、Co。
  3. 与 FCC 的区别只在堆垛序：FCC 密排面是 ABC 三层周期、HCP 是 AB 两层周期（配位数相同，都是 12）。
  4. BCC 的 {112} 面堆垛序=ABCDEF 六层周期。
  5. 沿 ⟨111⟩ 剪切 1/6⟨111⟩ 后，局部原子环境变成类 HCP（ABAB 式）的堆垛——原文强调"并非精确 HCP，只是局部原子环境与之相似"。
  6. 孪晶形核路径正经过这个类 HCP 构型（图 6c 插图）→ 因此 HCP 结构相对 BCC 的能量差 ΔE 是孪晶形核难易的代理指标：ΔE 小（Fe、VB 族）→ 类 HCP 亚稳层错容易形成 → 孪生容易；ΔE 大（Mo、W，≈0.45 eV/atom）→ 无亚稳层错 → 孪生困难。
  7. Re 等溶质降低 ΔE → 促孪生；温度推广：ΔE→ΔG=ΔE−TΔS（熵差可能使高温下亚稳谷变浅消失）。

    8. 结论：HCP=ABAB 密排堆垛的六方结构；本文用"类 HCP"描述孪生剪切后的局部环境，用 ΔE 当孪生难易的标尺。

10-13 减约束滑移法（RC）是什么？请详细解释

先备知识

  • γ 线计算：逐步剪切+逐步优化+记能量（10-03）。
  • 结构优化：让原子位置弛豫到能量最低。
  • 口径=同一物理量、不同计算协议给不同值。

动机（为什么要发明它）

经典 GSFE/γ 线计算用刚性剪切（原子全固定或只放法向），不允许多层弛豫，因此看不到孪晶胚这种"多层协同重排"的产物；而真实形核场景（裂纹尖端、晶界三叉结点）里切应力只在几个原子层内被局部放大——需要"局部剪切+大部分自由度弛豫"的计算设置才能复现这个场景。

六步流程

  1. 建超胞：BCC {112} 层平板+真空（纯金属 12 层、合金 16 层，真空约 15 Å）。
  2. 选滑移面（如图 1a 第 6、7 层之间），记滑移方向 x（=⟨1̄1̄1⟩）、面内垂直方向 y、面法向 z。
  3. 把滑移面以上全部原子沿 x 逐步位移，增量 Δs=0.04b=0.02⟨111⟩（b=½⟨111⟩ 模长）。
  4. 每步位移后做结构优化，只固定滑移面紧邻上下两层（第 6、7 层）原子的 x 坐标，其余全部自由度（含其他层的 x）弛豫。
  5. 记录每步能量 → γ_rc(s) 曲线。
  6. 观察 s 增大过程中是否自发出现孪晶胚：Fe/VB/Cr 在 s_c≈0.4b 处出现 2 层孪晶；Mo/W 无。

    7. 名字来源："减约束"=滑移方向约束只保留在滑移面两侧各一层，其余层连滑移方向都放开了（对比：γ_fix-x-y-z 全固定、γ_fix-x 只放 y/z）。

    生长步骤（同一思想）：在 2 层胚上方 TB 以上（第 8 层及以上）再施加 Δs，固定 TB 上下各 2 层（第 7、8 层）的 x，优化 → 得到孪生/反孪生方向生长能垒 γ_utw-t / γ_utw-at。

    双滑移面变体（Mo/W 的 3 层孪晶）：在两个连续滑移面上下各施一次 s_c≈0.33b（图 1d：第 8–12 层沿上滑移面、第 1–6 层沿下滑移面反向），固定第 6、7、8 三层 x 优化 → 3 层镜面孪晶。

    产出与用途：γ_rc 线（含亚稳谷）、γ_2tw（2 层胚超出能）、γ_ud（全位错能垒）、γ_utw-t/at（生长能垒）、δ（近等腰 TB 平移）——进而代入 Rice 判据（式 (9)）换算 K_It/K_Ie、与 K_Ic 比较，预测裂纹尖端韧/脆行为（WRe 临界 Re 浓度 22/28/48 at.%，对应 {112}/{110}/{100} 裂纹面）。

    局限（原文自述）：① 形核仍需"假想原子位移"启动（方法给出路径与能垒，不是自发形核）；② 零温、VCA 平均合金（不捕捉溶质局域效应）；③ 正应力依赖（GSFH 线）与温度（ΔG）是边界条件，需另算。

    结论：RC=把约束减到"只剩滑移面上下两层的剪切方向坐标"，让其余层自由弛豫——这样能量景观里才出现孪晶胚的"坑"，进而算出形核与生长的全部能垒。
